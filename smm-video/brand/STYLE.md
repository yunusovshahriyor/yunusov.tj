# Стили ягона — «VS Code Dark + бунафш»

**Ҳамаи мавод** бо ҳамин стил сохта мешавад: Reels, видеоҳои YouTube, муқоваҳо, баннерҳо, сторис ва карусел,
PDF-шпаргалка, расмҳои Telegram ва Chatplace, инчунин **барномаҳо** (IDE, бозиҳо, саҳифаҳои сайт барои дарсҳо).
Рангҳо ва ҷузъҳои тайёр: `brand.css` (ба ҳар HTML пайваст кунед ё тағйирёбандаҳоро нусха кунед).
Намуна: `../youtube/channel/banner.jpg`.

## 1. Ранг
| Нақш | Ранг | Кай |
|---|---|---|
| Замина | `#1E1E1E` | ҳамеша (на сафед, на коғаз) |
| Панел / корт | `#252526`, `#2D2D30`, хат `#3C3C3C` | кортҳо, тугмаҳо, редактор |
| Матн | `#D4D4D4`; сарлавҳа `#FFFFFF`; хира `#8B949E` | |
| Код | `let` `#569CD6`, матн `#CE9178`, рақам `#B5CEA8`, функсия `#DCDCAA`, шарҳ `#6A9955`, бирюзаӣ `#4EC9B0`, кабуд `#4FC1FF` | ҳамеша мисли VS Code |
| Дуруст / хато | `#4EC9B0` / `#F48771` | натиҷа, санҷиш |
| **Аксент** | бунафш `#BD93F9` → гулобӣ `#FF79C6` | 1–2 ҷой дар кадр: калимаи асосӣ, тугмаи асосӣ, ишора |

Қоидаи 80/15/5: 80% замина ва панелҳои тира, 15% рангҳои код, **5% аксенти неон**. Неон зиёд — чашм хаста мешавад.

## 2. Ҳарф
- Матн: **Inter** (сарлавҳа 800–900, матн 600). Код: мономатн (JetBrains Mono / DejaVu Sans Mono), бе лигатура (`>=` на `≥`).
- Сатри болоии хурд (kicker): мономатн, ҲАРФИ КАЛОН, бунафш, фосила 2px.
- Як сарлавҳаи калон дар кадр; матн кӯтоҳ.

## 3. Ҷузъҳо
- **Код** ҳамеша дар блоки тира бо рангҳои VS Code; дар видео — дар IDE-и худамон.
- **Ишора ба код**: чорчӯбаи бунафш бо рӯшноӣ + тамғаи pill (`.mark`, `.pill.accent`).
- **Кортҳо**: `#252526`, кунҷ 16px, хати `#3C3C3C`.
- **Қуттии картонӣ `age`** — рамзи силсила, ранги картон бетағйир (`#E2B070` → `#C8975A`).
- Эмодзи — кам, танҳо ҳамчун нишона.

| Барномаҳо (IDE, бозӣ) | — | ҳамин тағйирёбандаҳои `brand.css`; брендинг (ном, лого) дар интерфейс нест |

## 5. Намекунем
- Заминаи сафед/коғазӣ дар маводи нав.
- Зиёда аз ду ранги неон дар як кадр, матни неон дар ҷумлаҳои дароз.
- Рангҳои тасодуфӣ берун аз ин ҷадвал.
