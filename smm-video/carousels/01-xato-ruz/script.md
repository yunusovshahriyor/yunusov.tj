# Карусел «Хатои рӯз: = ё ===» (5 слайд) — нусхаи 1 (интизори тасдиқ)

Фикри ягона: **`=` қимат мегузорад, `===` муқоиса мекунад.**
Мақсад: сабт (save) ва шарҳ. Дар карусел ба курс даъват нест.
Стили: `brand/STYLE.md` (VS Code Dark + бунафш), 1080×1350 (4:5). Код санҷида шуд дар Node.js.

## Слайд 1 — хук
- Сарлавҳа: **Ин шарт ҳамеша «дуруст» мегӯяд 😱**
- Код:
  ```js
  let age = 12;
  if (age = 18) {
    console.log("Дароед");
  }
  ```
- Зеризабон: «Синну сол 12, аммо «Дароед» чоп мешавад. Чаро?» → свайп ➜

## Слайд 2 — чӣ шуд
- Сарлавҳа: **Як баробар қимат мегузорад**
- Матн: `age = 18` — ин «ба age қимати 18 бидеҳ» аст. Муқоиса нест.
- Қуттии `age`: 12 → 18 (стрелка). Барнома 18-ро «дуруст» мешуморад, шарт ҳамеша мегузарад.

## Слайд 3 — дуруст
- Сарлавҳа: **Барои муқоиса — се баробар**
- Код:
  ```js
  let age = 12;
  if (age === 18) {
    console.log("Дароед");
  }
  // ҳеҷ чиз чоп намешавад
  ```
- Зеризабон: «ҳоло 12 ≠ 18, пас «Дароед» чоп намешавад»

## Слайд 4 — ёдгорӣ
- Сарлавҳа: **Ёд гиред**
- Ҷадвал:
  | Нишона | Чӣ мекунад |
  |---|---|
  | `=` | қимат мегузорад |
  | `===` | муқоиса мекунад (қимат + навъ) |
- Маслиҳат: «Ҳамеша `===` нависед — `"5" == 5` дуруст аст, `"5" === 5` не.»

## Слайд 5 — санҷиш + даъват
- Сарлавҳа: **Санҷиш**
- Код:
  ```js
  let x = 5;
  console.log(x === "5");
  ```
- Савол: «Чӣ чоп мекунад? Ҷавобро дар шарҳ нависед 👇» (ҷавоб: `false` — навъи рақам ва матн фарқ мекунад)
- Поён: «🔖 Захира кунед» · «Калимаи «ХАТО»-ро нависед — видеои «3 хатои рӯзи аввал»-ро ба Direct мефиристам»

## Матни зери пост (caption.txt, пешниҳод)
Як баробар ё се баробар? Як нишона — ва шарт ҳамеша «дуруст» мегӯяд 😱
Дар 5 слайд мефаҳмед, фарқи `=` ва `===` чист.

Санҷиш: let x = 5; console.log(x === "5") — чӣ чоп мекунад? 🤔 Ҷавобро дар шарҳ нависед.

Калимаи «ХАТО»-ро ҳам нависед — видеои «3 хатои рӯзи аввал»-ро ба Direct мефиристам ▶️
🔖 Захира кунед, то фаромӯш накунед.
