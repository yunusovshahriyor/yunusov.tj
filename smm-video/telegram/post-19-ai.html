Дарси 13: Зеҳни сунъӣ — ёвар, на ҷонишин Зеҳни сунъӣ зуд менависад, вале баъзан хато мекунад. Масъулият бар души шумост: хонед, фаҳмед ва санҷед. 
function add(a, b) { return a + b; }
console.log(add(25, 1));        // 26
console.log(add("25", 1));      // 251, матн!
console.log(add(Number("25"), 1)); // 26
Се қоида: 1. Дақиқ пурсед — чӣ мехоҳед ва бо кадом маълумот. 2. Кодро хонед ва бифаҳмед. 3. Иҷро кунед ва санҷед — бо рақам, бо матн, бо холӣ. Агар хато шуд — хаторо ба зеҳни сунъӣ нишон диҳед ва пурсед: «Чаро?» 🧠 Санҷиш: add("10", 5) чӣ чоп мекунад? Ҷавобро дар шарҳ нависед 👇
