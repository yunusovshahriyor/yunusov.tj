🪪 Дарси 6: Объект Барои сабти маълумоти як одам даҳ тағйирёбанда лозим нест — як объект кифоя аст. 
let person = { name: "Алӣ", age: 25, city: "Душанбе" };
console.log(person.name);  // Алӣ
person.age = 26;
• Объект = ном + қимат, мисли шиноснома • person.name — қимат аз рӯи ном • person.age = 26 — иваз кардани қимат • Рӯйхат — бо шумора, объект — бо ном (дарси 4) 🧠 Санҷиш: person.age = 30 навиштем. console.log(person.name, person.age) чӣ чоп мекунад? Ҷавобро дар шарҳ нависед 👇
