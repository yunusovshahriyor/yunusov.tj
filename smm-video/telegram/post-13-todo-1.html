📝 Дарси 9: To-Do — лоиҳаи ҳақиқӣ (қисми 1) Дафтари вазифаҳоро дар код нигоҳ доштан мумкин аст — бо як рӯйхат ва як давр. 
let tasks = [
  { text: "нон харидан", done: false },
  { text: "дарс хондан", done: false }
];
tasks.push({ text: "занг задан", done: false });

for (let i = 0; i < tasks.length; i++) {
  console.log(i + 1 + ". " + tasks[i].text);
}
// 1. нон харидан
// 2. дарс хондан
// 3. занг задан

tasks[0].done = true;
• Вазифа = объект: text + done (дарси 6) • Рӯйхат — вазифаҳо бо шумора аз 0 (дарси 4) • for — чоп кардани ҳама (дарси 3) 🧠 Санҷиш: дар рӯйхат се вазифа ҳаст. console.log(tasks[1].text) чӣ чоп мекунад? Ҷавобро дар шарҳ нависед 👇
