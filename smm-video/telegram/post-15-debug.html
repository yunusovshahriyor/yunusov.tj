Дарси 8: Хатогӣ ва дебаг 25 + 1 = 251? Компютер хато накардааст — хато дар код аст. Усули ёфтан: бубин, санҷ, ислоҳ кун. 
let age = "25" + 1;
console.log(age);          // 251, мехостем 26
console.log(typeof age);   // string — матн!
let fixed = Number("25") + 1;
console.log(fixed);        // 26
Қадами 1 — бубин: чӣ гирифтем ва чӣ мехостем. Қадами 2 — санҷ: typeof ва console.log нишон медиҳанд, ки «25» матн аст. Қадами 3 — ислоҳ кун: Number("25") матнро ба рақам табдил медиҳад. 🧠 Санҷиш: console.log("10" + 5) чӣ чоп мекунад? Ёдовар: «10» дар қавс — матн. Ҷавобро дар шарҳ нависед 👇
