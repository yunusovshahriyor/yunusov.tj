😅 Дарси 7: 3 хатои рӯзи аввал

Се хато, ки ҳар навкор мекунад — ва чӣ тавр онҳоро ислоҳ кардан.

1️⃣ «=» ба ҷои «===»
if (age = 18) { } — ❌ қимат мегузорад
if (age === 18) { } — ✅ муқоиса мекунад

2️⃣ Ҳарфи калон ва хурд
Console.log("Салом") — ❌ ReferenceError
console.log("Салом") — ✅

3️⃣ Қавси фаромӯшшуда
console.log("Салом" — ❌ SyntaxError
console.log("Салом") — ✅

💡 Паёми хаторо бихонед — он сатри хаторо нишон медиҳад. Хато душман нест — роҳнамост.
