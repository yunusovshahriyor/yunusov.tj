## 3. Тартиби кор (ҳамеша ҳамин қадамҳо)
1. **Мавзӯъ** аз `PLAN.md` гирифта мешавад.
2. **Матн** (сенария) → ба муаллиф нишон медиҳем → **тасдиқ**.
3. **Матн барои овоз** (рақамҳо бо калима, лотинӣ бо кириллӣ) → **тасдиқ**.
4. **Овоз** — як бор дар ElevenLabs. Такрор танҳо бо иҷозати муаллиф (кредит!).
5. **Монтаж**: саҳнаҳо, субтитр, садо, мусиқӣ → кадрҳои санҷишӣ худамон месанҷем.
6. **Нишон додан**: видео + муқова + матни зери пост → **тасдиқ**.
7. **Нашр**: Instagram — муаллиф худаш дастӣ; Telegram — бот, танҳо пас аз «Нашр кун».
8. **Сабт**: файлҳо дар папкаи мувофиқ, `telegram/published.md` нав мешавад, commit + push.

Ҳеҷ чиз бе тасдиқи муаллиф нашр намешавад.

- Ростқавлӣ: видеоҳоро «сабти дастӣ» ё «аз ҷониби одам» муаррифӣ намекунем; сифатнок месозем, бо фиреб не.

## 6. Reels (1080×1920, 9:16)
- Дарозӣ: **45–75 с**. Паузаҳои дароз нест.
- Сохтор: хук (1–2 с: савол/натиҷа) → мисоли ҳаётӣ → код → «компютер чӣ тавр мебинад» → хулоса дар як сатр → савол/санҷиш барои шарҳ → калимаи рамз → дарси оянда.
- Шапка: «ШАҲРИЁР ЮНУСОВ · NN / БАРНОМАСОЗӢ» (стили `brand/STYLE.md`); субтитр калима ба калима (караоке); садоҳо (whoosh, pop, key, ding) ва мусиқии лоу-фай.
- Муқова `cover.jpg` (1080×1920, матни калон дар маркази 1080×1350).
- Матни зери пост `caption.txt`: 2–3 ҷумла + савол + калимаи рамз + **5 хештег**.
- Калимаи рамз (`ДАВР`, `ШАРТ`, `РӮЙХАТ`, …) → бот (Chatplace) шпаргалкаро ба Direct мефиристад.
- Намуна барои сохтан: `reels/04-array/build/` (build.py → audio.py → render.js → ffmpeg).

## 7. YouTube (1920×1080, 16:9)
- Дарозӣ: **5–8 дақ.** Суръати хониш табиӣ, ором.
- Сохтор: хук (≤ 20 с) → образ → код дар IDE (ҳарф ба ҳарф, бо овоз) → мисолҳо → хатогиҳои маъмул → вазифа (бо «пауза кунед» + ҷавоб) → хулоса → дарси оянда + обуна.
- Ҳар 5–15 сония чизе тағйир меёбад: зум ба код, тамғаҳои ранга, курсор, саҳнаи нав — то тамошобин дилгир нашавад.
- Ҳатман: субтитр дар поён, хати пешрафти қисмҳо, **чаптерҳо** аз вақти воқеӣ, файли `.srt`, муқова **1280×720**, ном + тавсиф дар `youtube.md` (пайванди IDE: `https://yunusovshahriyor.github.io/yunusov.tj/ide/#dars-N`).
- Мусиқӣ оромтар аз Reels (баланди ~−21 дБ дар паузаҳо, зери овоз худкор паст мешавад).
- Намуна барои сохтан: `youtube/01-variable/build/` (build.py → render.js/runall.sh → mix.py → ffmpeg).
