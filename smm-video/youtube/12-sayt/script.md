## 0:45 · Образи ресторан (≈60 сония)
**Тасвир:** ресторан: меҳмон 🙋 ба ошхона намеравад — официант 🛎️ мебарад ва меорад; ошхона 🧑‍🍳; мувофиқат: меҳмон = браузер (клиент), ошхона = сервер, официант = интернет; тирҳо «дархост →» ва «← ҷавоб».

Аввал тасаввур кунед, ки дар ресторан нишастаед. Ба ошхона худатон намеравед. Ба официант мегӯед: «Ман ошро мехоҳам». Официант ба ошхона меравад, ош меорад.
Интернет ҳам ҳамин тавр кор мекунад. Шумо — меҳмон, яъне браузер. Онро аксар вақт клиент мегӯянд: касе, ки чизе мепурсад. Ошхона — сервер: компютери калон, ки сайтро нигоҳ медорад ва шабонарӯз кор мекунад. Официант — интернет: пурсишро мебарад ва ҷавобро меорад.
Ду калима дар хотир доред. Дархост — вақте ки браузер чизе мепурсад. Ҷавоб — вақте ки сервер чизе медиҳад. Тамоми сайтҳои ҷаҳон ҳамин тавр кор мекунанд: дархост ва ҷавоб. Хулосаи имрӯза ҳамин аст.
Ва ёдатон ҳаст дарси ёздаҳум: се файл — HTML, CSS ва JavaScript? Ана ҳамон се файл дар ҷавоб меоянд. Баъд мебинем, ки чӣ тавр.

## 1:45 · Суроға: аз чӣ иборат аст? (≈70 сония)
**Тасвир:** IDE-и мо: сатр `https://yunusov.tj/ide/#dars-12` → се қисм бо нишона: «протокол» (`https://`), «домен» (`yunusov.tj`), «роҳ» (`/ide/`), «ҳаш» (`#dars-12`); тасвир: суроғаи хона: шаҳр · кӯча · хона.

Ҳар дархост бо суроға оғоз мешавад. Мо ба суроға дар ҳар рӯз менигарем, аммо кам мефикрем, ки он аз чанд қисм иборат аст. Мисол: HTTPS, ду нуқта, ду хати ҷаҳида, yunusov.tj, хати ҷаҳида, IDE, хати ҷаҳида.
Қисми якум — протокол: HTTPS. Ин «забон»-и гуфтугӯ аст: браузер ва сервер бо кадом қоидаҳо ҳарф мезананд. Дар охири он ҳарфи эс — бехатар; дар бораи он баъд мегӯем.
Қисми дуюм — домен: yunusov.tj. Ин номи сайт аст, мисли номи шаҳр.
Қисми сеюм — роҳ: IDE. Ин ҷои дақиқи он чизест, ки мехоҳем: мисли кӯча ва рақами хона. Агар роҳ нест, сервер саҳифаи асосиро медиҳад.
Ва охири суроға, баъд аз нишони решетка — ин қисм ба сервер намеравад: браузер худаш бо он ба ҷои дуруст дар саҳифа меравад.
Суроғаи хона дар шаҳр низ ҳамин тавр: шаҳр, кӯча, хона. Аз бузург ба хурд.

## 2:55 · Домен ва DNS: «китоби телефон» (≈60 сония)
**Тасвир:** браузер → «юнусов.tj = ?» → DNS (китоби телефон) → `203.0.113.10`; ду ҷадвал: «ном → рақам»; сипас браузер → сервер бо IP.

Мушкил ин аст: компютерҳо номҳоро намефаҳманд. Онҳо танҳо рақамҳоро мефаҳманд. Ҳар сервер суроғаи рақамӣ дорад — онро IP мегӯянд. Он аз чор рақам иборат аст, ки бо нуқта ҷудо шудаанд — мисолашро дар экран мебинед.
Лекин IP-ро аз ёд кардан душвор аст. Аз ин рӯ номҳо — доменҳо — ихтироъ шудаанд.
Пас, пеш аз дархост браузер як савол медиҳад: «yunusov.tj кист? Суроғаи рақамиаш чист?» Ин савол ба хидмати махсус меравад — DNS. Он мисли китоби телефон аст: ном медиҳед — рақам мегиред.
Баъд браузер дархостро ба ҳамон рақам мефиристад. Ва ин қадами аввал аст — ҳанӯз як миллисония нагузашта.
Ба ёд гиред: домен барои одам, рақам барои компютер. Китоби телефон — онҳоро пайваст мекунад.

## 3:55 · Дархост: GET ва POST (≈55 сония)
**Тасвир:** IDE: `let request = { method: "GET", url: "/" };` (объект аз дарси 6); тагашро нишона: «method — чӣ мехоҳем», «url — аз куҷо»; ду корт: GET — «деҳ» (саҳифа, сурат), POST — «мефиристам» (шакл, тугмаи «Лайк»); `POST /like`.

Акнун худи дархост. Дархост — ин паёмест, ки браузер ба сервер мефиристад. Дар он ду қисми муҳим ҳаст: усул ва роҳ.
Ёдатон ҳаст объект аз дарси шашум? Дархостро ҳамин тавр навиштан мумкин: let request, баробари, қавси фигурӣ: method — GET, url — хати ҷаҳида. Method мегӯяд, ки чӣ мехоҳем. А url — аз куҷо.
Ду усули асосӣ ҳаст. GET — «ба ман деҳ». Мо саҳифа мекушоем, сурат мебинем — ҳамааш GET аст.
POST — «ман ин чизро мефиристам». Масалан, шумо шаклро пур кардед ва тугмаи «Фиристодан»-ро пахш кардед. Ё тугмаи «Лайк»: браузер ба сервер мегӯяд: «POST, хати ҷаҳида like — ман лайк мондам».
Ба ёд гиред: GET — мегирем, POST — мефиристем.

## 4:50 · Сервер ва ҷавоб: статус-код (≈125 сония)
**Тасвир:** IDE: функсияи `server(req)` бо `if` (дарси 2) ва `return` (дарси 5); иҷро `"/"` → `{ status: 200, body: "<h1>Салом!</h1>" }`; `"/about"` → 200; `"/shop"` → 404; дар экран корти «200 — ҳамааш хуб · 404 — ёфт нашуд · 500 — хатои сервер».

Сервер дархостро гирифт. Ва акнун ӯ бояд ҷавоб диҳад. Дар сервери воқеӣ барномаи калон кор мекунад. Мо барои фаҳмидан як намунаи хурд месозем — оддӣ ва бо коди худамон. Ин сервери воқеӣ нест, аммо принсип ҳамон аст.
Ба IDE мегузарем. Function server, дар қавс req. Дар дохил — шарт аз дарси дуюм: агар req.url баробари хати ҷаҳида — ин саҳифаи асосӣ аст. Return, объект: status — дусад, body — «Салом!» дар тегҳои h1.
Баъд боз шарт: агар req.url баробари /about — return объекти дигар: status — дусад ва body — «Ман барномасоз мешавам».
Ва дар охир — return барои ҳама чизи дигар: status — чорсаду чор, body — «Саҳифа ёфт нашуд».
Ёдатон ҳаст return аз дарси панҷум? Функсия ҷавоб бармегардонад. Сервер ҳам ҳамин тавр: ҷавоб бармегардонад.
Даъват мекунем: console.log, server, дар қавс — GET ва хати ҷаҳида. Иҷро: status дусад ва body — «Салом!». Саҳифа ёфт шуд!
Ҳоло дархост ба роҳи дигар: /shop. Иҷро — чорсаду чор. Саҳифа ёфт нашуд.
Ана ин рақам — статус-код. Дар ҷавоб ҳамеша як рақам ҳаст, ки мегӯяд, чӣ шуд. Се рақами маъруф: дусад — ҳамааш хуб. Чорсаду чор — саҳифа ёфт нашуд: суроға нодуруст аст ё файл нест. Панҷсад — хатои худи сервер: хатои ошхона, на аз меҳмон.
Ва як рақами дигар, ки аксар вақт пинҳон аст: сесаду як. Он мегӯяд: «Саҳифа ба ҷои дигар гузашт». Браузер худаш ба суроғаи нав меравад, ва шумо чизеро пай намебаред.
Шумо чорсаду чор-ро борҳо дидаед. Акнун медонед: ин танҳо ҷавоби сервер аст: «Чунин чизе надорам».

## 6:55 · Браузер ҷамъ мекунад: се файл (≈65 сония)
**Тасвир:** ҷавоб: `index.html` меояд → дар дохили он «ба `style.css` ва `script.js` низ ниёз дорам» → ду дархости нав → ҳар се файл → хона зинда мешавад (аз дарси 11); схемаи F12 → Network: рӯйхати `index.html 200`, `style.css 200`, `script.js 200` (бо пайдо шудани «схема»).

Ёдатон ҳаст се файл аз дарси ёздаҳум? Акнун мебинем, ки онҳо чӣ тавр меоянд.
Сервер дар ҷавоби аввал индекс нуқта HTML-ро мефиристад. Браузер онро мехонад ва дар дохили он мебинад: «Ба стайл нуқта CSS ва скрипт нуқта JS низ ниёз дорам». Он ба сервер ду дархости нав мефиристад. Сервер ду ҷавоби нав медиҳад.
Ва ҳамаро браузер як ҷо ҷамъ мекунад: HTML — деворҳо, CSS — ранг, JavaScript — барқ. Ва саҳифаи зинда пайдо мешавад.
Худатон бубинед: дар браузер F12-ро пахш кунед ва ҷадвали Network-ро кушоед. Дар он рӯйхати ҳар дархост ва ҳар ҷавоб аст: номи файл, статус — дусад, андоза ва вақт. Дар экран мо онро намунавӣ нишон додем, аммо дар браузери худатон ҳақиқиашро мебинед.
Тавсия: саҳифаи ҳар сайтро бикушоед ва F12-ро пахш кунед. Ин беҳтарин «рентген»-и сайт аст.

## 8:00 · Фронтенд ва бекенд (≈65 сония)
**Тасвир:** ресторан: зал (меҳмон) ва ошхона (ошпаз); ду бахш: «фронтенд — он чизе, ки мебинед» (HTML, CSS, JS дар браузер) ва «бекенд — дар сервер» (қабули дархост, ҳисоб, база); корти «JavaScript — ҳам дар браузер, ҳам дар сервер».

Акнун як истилоҳи муҳим. Ресторанро ёд кунед: дар зал меҳмон нишастааст, дар ошхона ошпаз кор мекунад. Дар сайт ҳам ду тараф ҳаст.
Тарафи меҳмон — он чизест, ки шумо мебинед ва пахш мекунед: HTML, CSS ва JavaScript дар браузер. Онро фронтенд мегӯянд — «қисми пеш».
Тарафи ошхона — он чизест, ки шумо намебинед: барномае дар сервер, ки дархостро қабул мекунад, лайкро ҳисоб мекунад, маълумотро дар база нигоҳ медорад ва ҷавоб тайёр мекунад. Онро бекенд мегӯянд — «қисми паси».
Ва як хабари хуш: JavaScript, ки мо меомӯзем, дар ҳарду тараф кор мекунад. Дар браузер — барои саҳифа. Дар сервер — барои бекенд. Сервери намунавии мо дар IDE ҳам JavaScript буд.
Яъне, бо як забон шумо ҳам залро месозед, ҳам ошхонаро. Чунин барномасозро full-stack мегӯянд.

## 9:05 · Сайти зинда: JSON ва тугмаи «Лайк» (≈85 сония)
**Тасвир:** тугмаи «Лайк» (25) → браузер: `POST /like` → сервер → ҷавоб `{"likes":26,"liked":true}`; IDE: `JSON.parse` ва `JSON.stringify`; қуттии `age` 25 → 26 ба шакли `likes`.

То ҳол мо саҳифаи оддӣ дидем: ҳамеша як хел. Аммо сайти зинда — масалан, Instagram — ҳар дафъа чизи нав нишон медиҳад. Чӣ тавр?
Агар шумо тугмаи «Лайк»-ро пахш кунед, script.js ба сервер дархости POST мефиристад. Сервер лайкро дар ҷадвали худ менависад ва ҷавоб бармегардонад — матн, аммо бо қоидаи махсус. Онро JSON мегӯянд.
Ёдатон ҳаст объект аз дарси шашум? JSON — ҳамон объект, танҳо дар шакли матн. Бубинем дар IDE.
Let answer, баробари матн: қавси фигурӣ, likes — бисту панҷ, liked — false. Ин матн аз сервер омад.
Баъд let data баробари JSON.parse, answer. Parse — матнро ба объект табдил медиҳад. console.log, data.likes — бисту панҷ.
Ҳоло лайк мемонем: data.likes баробари data.likes плюс як; data.liked баробари true. Ва ба матн бармегардонем: JSON.stringify. Натиҷа: likes — бисту шаш, liked — true.
Ёдатон ҳаст қуттии бисту панҷ аз дарси якум? Ана бисту шаш шуд. Ин матн ба сервер бармегардад — ва ҳамаи одамон лайки навро мебинанд.
Пас: браузер мепурсад, сервер ҷавоб медиҳад — ва ҷавоб гоҳо файл, гоҳо маълумот аст.

## 10:30 · Чаро гоҳо сайт суст мекушояд (≈45 сония)
**Тасвир:** се корт: «сервер дур аст» (хати дароз), «файл калон аст» (сурати вазнин), «меҳмонҳо бисёранд» (ресторани пур); тир: «хурд кардани сурат · серверҳо дар шаҳрҳои гуногун».

Ба назар як лаҳза, аммо баъзан сайт суст мекушояд. Чаро?
Якум: сервер дур аст. Ҷавоб мисли нома аст: ҳар қадар дуртар, ҳамон қадар дертар мерасад.
Дуюм: файлҳо калон ҳастанд. Як сурати вазнин аз даҳҳо саҳифаи матн вазнинтар аст. Аз ин рӯ суратҳоро хурд мекунанд.
Саввум: меҳмонҳо бисёранд. Ресторан пур аст — официант барои ҳама вақт надорад. Сервер ҳам ҳамзамон ба садҳо ҳазор нафар ҷавоб медиҳад.
Ба ҳамин сабаб сайтҳои калон серверҳои зиёд доранд ва нусхаи файлҳоро дар шаҳрҳои гуногун нигоҳ медоранд, то ҷавоб ба меҳмон наздиктар бошад.

## 11:15 · Бехатарӣ: қулф дар суроға (≈35 сония)
**Тасвир:** ду нома: «http — открытка» (ҳама мехонанд) ва «https — конверти пӯшида» (танҳо сервер); сатри суроға бо қулф 🔒; нишона: «рамз ва корт — танҳо дар сайтҳои бо қулф».

Ва ҳоло дар бораи қулф дар суроға. Агар суроға бо http сар шавад, паём дар роҳ мисли открытка аст: ҳар касе, ки аз паҳлӯ гузарад, онро хонда метавонад. Агар бо https сар шавад — паём дар конверти пӯшида меравад: танҳо сервер онро мекушояд.
Аз ин рӯ ба сайтҳое, ки рамз, рақами корт ё маълумоти шахсӣ мепурсанд, танҳо дар ҳолати қулф бовар кунед. Агар қулф нест — маълумоти муҳимро ворид накунед.

**Тасвир:** се корт: «1 · Сайт дар компютери ман нест — дар сервер аст», «2 · 404 = суроға нодуруст ё файл нест», «3 · Ном ва роҳ дақиқ навишта мешаванд: /about ≠ /About».

Ва се хатои маъмул.
Якум: «Сайти ман дар компютери ман аст — пас ҳама мебинанд». Не. Файл дар компютери шумо танҳо барои шумо аст. Барои ҳама, файлҳо бояд дар сервер бошанд.
Дуюм: ба чорсаду чор бовар накунед, ки «сайт вайрон шуд». Аксар вақт сабаб оддитар аст: суроға нодуруст навишта шудааст ё файл дар ҷои дигар аст.
Саввум: ном ва роҳ дақиқ навишта мешаванд. Агар як ҳарф нодуруст бошад, суроға дигар мешавад: /about ва /About-ро сервер ду чизи гуногун мешуморад. Аз ин рӯ, пеш аз он, ки ҳайрон шавед, суроғаро бодиққат санҷед.

## 12:35 · Роҳи як дархост: ҳама қадамҳо (≈55 сония)
**Тасвир:** тасмаи 7 қадам дар як сатр: суроға → DNS → GET → сервер → ҷавоб 200 → `style.css` + `script.js` → саҳифа; ҳар қадам бо рақам ва нишона; дар охир: «7 қадам — як лаҳза».

Акнун ҳамаро аз аввал то охир як бор ҷамъ мекунем. Фарз кунед, шумо суроғаи yunusov.tj-ро менависед.
Қадами якум: браузер суроғаро ба қисмҳо ҷудо мекунад — протокол, домен, роҳ.
Қадами дуюм: DNS номро ба рақами сервер табдил медиҳад.
Қадами сеюм: браузер ба ҳамон рақам дархост мефиристад — GET ва роҳ.
Қадами чорум: сервер дархостро мефаҳмад ва ҷавоб тайёр мекунад.
Қадами панҷум: ҷавоб бармегардад — бо статус-код, масалан дусад, ва бо файли index.html.
Қадами шашум: браузер дар дохили он style.css ва script.js-ро мебинад ва онҳоро низ мепурсад.
Қадами ҳафтум: браузер ҳамаро ҷамъ мекунад — ва шумо саҳифаро мебинед. Агар тугмаро пахш кунед, дархости нав сар мешавад.
Ҳафт қадам — ва ҳамааш дар як лаҳза.

## 13:30 · Вазифаҳо ва санҷиш (≈80 сония)

Маслиҳат: пеш аз он ки ба IDE гузаред, бо қоғаз ва ё дар ақл муайян кунед, ки сервер ба ҳар роҳ кадом статус медиҳад. Баъд кодро иҷро кунед ва санҷед, ки дуруст фикр кардед ё не. Ҳамин тавр барномасозон кори худро месанҷанд.

## 14:50 · Хулоса ва даъват (≈65 сония)

## Код дар видео (санҷидашуда дар Node.js)
```js
let request = { method: "GET", url: "/" };

function server(req) {
  if (req.url === "/") {
    return { status: 200, body: "<h1>Салом!</h1>" };
  }
  if (req.url === "/about") {
    return { status: 200, body: "<p>Ман барномасоз мешавам.</p>" };
  }
  return { status: 404, body: "Саҳифа ёфт нашуд" };
}

console.log(server({ method: "GET", url: "/" }));        // { status: 200, body: '<h1>Салом!</h1>' }
console.log(server({ method: "GET", url: "/about" }).status);  // 200

console.log(server({ method: "GET", url: "/contact" }).status); // 404 (санҷиш)
```
