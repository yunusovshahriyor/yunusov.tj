## 0:00 · Хук (≈22 сония)
**Тасвир:** терминал: `☑ нон харидан` / `☐ дарс хондан` / `☐ занг задан`; «Чӣ тавр?»; дафтарча бо вазифаҳо. Дар кунҷ: «Дарси 9 · Лоиҳаи хурд».

Салом, дӯстон! Дафтари вазифаҳоро дар код нигоҳ доштан мумкин аст — бо як рӯйхат ва як давр. Ин аввалин лоиҳаи хурди мост.
Имрӯз онро аз сифр месозем: рӯйхати вазифаҳо, илова кардан, нишон додан ва иҷро шуд гуфтан. Дар охир санҷиши нав ҳаст. Оғоз мекунем!

## 0:24 · Образи дафтарча ва объект (≈55 сония)
**Тасвир:** дафтарча: ☐ нон харидан · ☐ дарс хондан; ҳар сатр → корти `{ text, done }` (ёдгорӣ: «корти шиноснома», дарси 6); кортҳо дар қатори `[ ]` бо шумораҳои 0, 1 (дарси 4).

Тасаввур кунед, ки дафтарча доред, ва дар он вазифаҳо навишта шудаанд: нон харидан, дарс хондан. Ҳар вазифа — як сатр ва нишона: иҷро шуд ё не.
Дар барномасозӣ ҳам ҳамин тавр. Ҳар вазифа — як объект, мисли корти шиноснома аз дарси шашум: матн ва ҳолат. Text — вазифа чист. Done — иҷро шуд ё не: true ё false.
Ва объектҳо дар рӯйхат меистанд — аз дарси чорум. Рӯйхат — дафтарча, объект — як сатри он.

## 1:20 · Аввалин рӯйхат дар IDE (≈75 сония)
**Тасвир:** IDE: `let tasks = [` / `{ text: "нон харидан", done: false },` / `{ text: "дарс хондан", done: false }` / `];`; `console.log(tasks[0].text)` → «нон харидан»; `tasks.length` → 2.

Ба IDE мегузарем. Пайванд дар тавсиф аст, ҳамроҳи ман нависед.
Менависем: let tasks баробари қавси чоркунҷа. Дар дохил — ду объект. Якум: text, «нон харидан», done, false. Вергул. Дуюм: text, «дарс хондан», done, false. Қавси ёпӣ ва нуқтавергул.
Ин дафтарчаи мо аст. Номи вазифаи аввал: console.log, tasks, қавси чоркунҷа, сифр, нуқта text. Иҷро. «Нон харидан»! Шумора аз сифр оғоз мешавад — ҳамон тавр, ки дар дарси чорум.
Ва console.log, tasks нуқта length — ду. Дар дафтарча ду вазифа ҳаст.

## 2:35 · Илова кардан: push (≈50 сония)
**Тасвир:** IDE: `tasks.push({ text: "занг задан", done: false });` — корти сеюм аз боло меафтад; `tasks.length` → 3.

Вазифаи нав илова мекунем. Ёдатон ҳаст push аз дарси рӯйхат? Tasks нуқта push, дар қавс — объекти нав: text, «занг задан», done, false.
Ҳоло console.log, tasks нуқта length — се! Дафтарча калон шуд.

## 3:25 · Нишон додан: давр (≈60 сония)
**Тасвир:** IDE: `for (let i = 0; i < tasks.length; i++) { console.log(i + 1 + ". " + tasks[i].text); }` → «1. нон харидан · 2. дарс хондан · 3. занг задан»; нишона: «давр — дарси 3».

Ҳоло ҳамаро чоп мекунем — бо давр, аз дарси сеюм. For, let i баробари сифр, i камтар аз tasks нуқта length, i плюс плюс.
Дар дохил: console.log, i плюс як, плюс «нуқта ва фосила», плюс tasks, i, нуқта text. Чаро i плюс як? Шумора аз сифр оғоз мешавад, лекин мо мехоҳем «як, ду, се» бинем.
Иҷро. Як — нон харидан. Ду — дарс хондан. Се — занг задан. Ҳамаи вазифаҳо як-як!

## 4:25 · Иҷро шуд: done ва шарт (≈70 сония)
**Тасвир:** IDE: `tasks[0].done = true;` + давр бо `if (tasks[i].done)` → `☑ нон харидан` / `☐ дарс хондан` / `☐ занг задан`; нишона: «шарт — дарси 2».

Ва акнун вазифаи аввалро иҷро мекунем: tasks, сифр, нуқта done, баробари true. Нон харида шуд!
Барои дидан ҳолатро ба давр илова мекунем — шарт аз дарси дуюм. Иф, tasks, i, нуқта done: console.log, «квадрати пур», плюс текст. Вагарна: console.log, «квадрати холӣ», плюс текст.
Иҷро. Квадрати пур — нон харидан. Квадрати холӣ — дарс хондан. Квадрати холӣ — занг задан. Дафтарча зинда шуд!

## 5:35 · Хато ва дебаг (≈55 сония)

Ва як хатои маъмул. Мо менависем: console.log, tasks, се, нуқта text. Иҷро. Хато: TypeError, Cannot read properties of undefined.
Ба дарси ҳаштум баргардем: бубин, санҷ, ислоҳ кун. Бубинед: хато мегӯяд — tasks, се — «муайян нашудааст». Санҷед: console.log, tasks нуқта length — се. Яъне шумораҳо — сифр, як, ду. Се вуҷуд надорад!
Ислоҳ: tasks, ду — охирин вазифа. Иҷро. «Занг задан»! Қоида: охирин шумора — length минус як.

Ва санҷиши нав: дар рӯйхат се вазифа ҳаст — нон харидан, дарс хондан, занг задан. Console.log, tasks, як, нуқта text — чӣ чоп мекунад? Ёдовар: шумора аз сифр оғоз мешавад. Видеоро пауза кунед ва фикр кунед.

## Код (санҷидашуда дар Node.js)
```js
let tasks = [
  { text: "нон харидан", done: false },
  { text: "дарс хондан", done: false }
];
console.log(tasks[0].text);          // нон харидан
console.log(tasks.length);           // 2

tasks.push({ text: "занг задан", done: false });
console.log(tasks.length);           // 3

for (let i = 0; i < tasks.length; i++) {
  console.log(i + 1 + ". " + tasks[i].text);
}
// 1. нон харидан
// 2. дарс хондан
// 3. занг задан

tasks[0].done = true;
for (let i = 0; i < tasks.length; i++) {
  if (tasks[i].done) {
    console.log("☑ " + tasks[i].text);
  } else {
    console.log("☐ " + tasks[i].text);
  }
}
// ☑ нон харидан
// ☐ дарс хондан
// ☐ занг задан

console.log(tasks[3].text);          // TypeError: Cannot read properties of undefined (reading 'text')
console.log(tasks[2].text);          // занг задан  (охирин шумора — length минус як)

// санҷиш
console.log(tasks[1].text);          // дарс хондан
```
