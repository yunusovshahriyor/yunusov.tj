# Дарси 13 — ҷавобҳои воқеии Claude (барои видео)

Чӣ тавр гирифта шуд: ҳар хоҳиш ба як зерагенти тозаи Claude фиристода шуд (бе контексти лоиҳа, бе асбобҳо; «чати оддӣ»). Матни ҷавоб дар поён **бе тағйир** оварда шудааст. Ин сабти экран нест, балки матни воқеии ҷавоб. Дар экран навишта мешавад: «ҷавоби воқеии Claude, ҳамчун матн нишон дода шудааст». Санаи гирифтан: 28.11.2026. Ҳар як ҷавоб якдафъа гирифта шудааст (такрор намешавад; натиҷаи нав метавонад фарқ кунад).

Санҷиши код дар Node.js: поёни файл.

## Хоҳиши 1 (норавшан)
> Функсия бинавис, ки ду рақамро ҷамъ мекунад.

Ҷавоб:

Албатта! Ин функсия ду рақамро ҷамъ мекунад.

**JavaScript:**
```js
function sum(a, b) {
  return a + b;
}

console.log(sum(2, 3)); // 5
```

**TypeScript (бо навъҳо):**
```ts
function sum(a: number, b: number): number {
  return a + b;
}
```

**Python:**
```python
def sum_numbers(a, b):
    return a + b

print(sum_numbers(2, 3))  # 5
```

Функсия ду параметр (`a` ва `b`) мегирад ва натиҷаи ҷамъи онҳоро бармегардонад. Агар забони дигар лозим бошад, бигӯед.

---

## Хоҳиши 2 (дақиқ)
> Дар JavaScript функсияи add бо параметрҳои a ва b бинавис, ки ду рақамро ҷамъ мекунад ва ҷавобро return мекунад. Рақамҳо гоҳо ҳамчун матн меоянд, масалан "25".

Ҷавоб:

Ин функсияи add дар JavaScript аст:

```js
function add(a, b) {
  return Number(a) + Number(b);
}

console.log(add(5, 3));     // 8
console.log(add("25", 5));  // 30
console.log(add("25", "7")); // 32
```

Шарҳ: агар `+`-ро бевосита истифода барем, `"25" + 5` натиҷаи `"255"` (пайваст кардани матн) медиҳад. Барои ҳамин аввал `Number()` ҳар ду параметрро ба рақам табдил медиҳад ва баъд ҷамъ мекунад.

Агар хоҳед, ки ҳангоми матни нодуруст (масалан `"abc"`) хато баргардонад, чунин навиштан мумкин аст:

```js
function add(a, b) {
  const x = Number(a);
  const y = Number(b);
  if (Number.isNaN(x) || Number.isNaN(y)) {
    throw new TypeError("a ва b бояд рақам ё матни рақамӣ бошанд");
  }
  return x + y;
}
```

## Хоҳиши 3 (миёна, навомӯз)
> Ман навомӯзам. Дар JavaScript функсия бинавис, ки миёнаи рӯйхати рақамҳоро ҳисоб мекунад.

Ҷавоб:

Салом! Ин функсияи оддӣ барои ҳисоб кардани миёна дар JavaScript:

```javascript
function miyona(royhat) {
  if (royhat.length === 0) {
    return 0; // агар рӯйхат холӣ бошад
  }

  let jam = 0;
  for (const raqam of royhat) {
    jam += raqam;
  }

  return jam / royhat.length;
}

// Намуна:
console.log(miyona([4, 8, 15, 16, 23, 42])); // 18
console.log(miyona([10, 20, 30]));           // 20
console.log(miyona([]));                     // 0
```

Шарҳ қадам ба қадам:

1. Функсия `miyona` як рӯйхат (массив) мегирад.
2. Агар рӯйхат холӣ бошад, `0` бармегардонем, то ба 0 тақсим накунем.
3. Тағйирёбандаи `jam` ҳамаи рақамҳоро ҷамъ мекунад (бо ҳалқаи `for...of`).
4. Дар охир ҷамъро ба шумораи элементҳо (`royhat.length`) тақсим мекунем. Ин миёнаи арифметикист.

Варианти кӯтоҳтар бо `reduce`:

```javascript
const miyona = (royhat) =>
  royhat.length ? royhat.reduce((a, b) => a + b, 0) / royhat.length : 0;
```

Ин ҳамон кор мекунад, фақат дар як сатр. Барои навомӯз версияи аввал равшантар аст, вале баъдтар `reduce`-ро ҳатман омӯзед, зеро он дар JavaScript бисёр истифода мешавад.

Агар хоҳед, метавонам чанд машқи иловагӣ пешниҳод кунам, масалан ёфтани рақами калонтарин ё медиана.

## Хоҳиши 4 (хато)
> Ин код дар ин сатр хато медиҳад:
>
> ```js
> function average(list) {
>   let sum = 0;
>   for (let i = 0; i < list.length; i++) { sum = sum + list[i]; }
>   return sum / list.length;
> }
> console.log(average());
> ```
>
> Паёми хато: TypeError: Cannot read properties of undefined (reading 'length')
> Ман интизор будам, ки барнома нол ё паём диҳад. Чаро ин хато мешавад ва чӣ тавр ислоҳ кунам?

Ҷавоб:

Чаро хато мешавад:

Дар охири код `average()`-ро бе аргумент даъват кардаед. Аз ин рӯ параметри `list` қимати `undefined` мегирад. Ҳангоми иҷрои `list.length` JavaScript кӯшиш мекунад хусусияти `length`-ро аз `undefined` бихонад ва хатои `TypeError: Cannot read properties of undefined (reading 'length')` медиҳад. Ин хато аввалин бор дар шарти ҳалқаи `for` (`i < list.length`) рух медиҳад.

JavaScript худаш нол ё паём намедиҳад. Он танҳо он чиро иҷро мекунад, ки навиштаед. Агар аргумент нагузаред, параметр `undefined` мемонад.

Чӣ тавр ислоҳ кардан:

1. Массивро ҳангоми даъват гузаред:

```js
console.log(average([1, 2, 3])); // 2
```

2. Барои он ки функсия худаш аз вуруди нодуруст ҳимоя кунад, санҷиш илова кунед:

```js
function average(list) {
  if (!Array.isArray(list) || list.length === 0) {
    return 0; // ё: throw new Error("Рӯйхати холӣ ё нодуруст");
  }
  let sum = 0;
  for (let i = 0; i < list.length; i++) {
    sum += list[i];
  }
  return sum / list.length;
}

console.log(average());          // 0
console.log(average([]));        // 0
console.log(average([1, 2, 3])); // 2
```

Санҷиши `list.length === 0` низ муҳим аст. Бе он, барои массиви холӣ `0 / 0` ҳосил мешавад ва натиҷа `NaN` мешавад.

Агар хоҳед, ки функсия ҳангоми вуруди нодуруст паём диҳад, на нол, `return 0`-ро бо `throw new Error(...)` иваз кунед. Он гоҳ хато бо матни фаҳмо баланд мешавад. Ин усул беҳтар аст, агар нол метавонад бо миёнаи воқеӣ омехта шавад.

Роҳи кӯтоҳтар бо қимати пешфарз барои параметр:

```js
function average(list = []) {
  if (list.length === 0) return 0;
  return list.reduce((a, b) => a + b, 0) / list.length;
}
```

Қимати пешфарз `= []` танҳо вақте кор мекунад, ки аргумент `undefined` бошад. Агар `null` гузаред, он кор намекунад. Барои ҳамин санҷиши `Array.isArray` боэътимодтар аст.

## Санҷиши ҷавобҳо дар Node.js (ман иҷро кардам)
| Код | Вуруд | Натиҷа |
|---|---|---|
| `sum` (хоҳиши 1) | `sum(2, 3)` | `5` ✅ |
| `sum` (хоҳиши 1) | `sum("25", 1)` | `251` ❌ (матн пайваст мешавад) |
| `add` (хоҳиши 2) | `add("25", 5)` / `add("25", "7")` | `30` / `32` ✅ |
| `add` (хоҳиши 2) | `add("abc", 1)` | `NaN` (версияи аввал; версияи дуюм хато мепартояд) |
| `miyona` (хоҳиши 3) | `[10, 20, 30]` / `[]` | `20` / `0` ✅ (ёвар холиро худаш ба назар гирифт) |
| `miyona` (хоҳиши 3) | `["10", "20"]` | **`510` ❌** (матн пайваст мешавад: `"010"+"20"` → `"01020"` / 2) |
| `miyona` (хоҳиши 3) | `miyona()` | `TypeError: Cannot read properties of undefined (reading 'length')` |
| `reduce`-версия | `["10", "20"]` | `510` ❌ |
| `average` (хоҳиши 4, версияи ислоҳшуда) | `average()` / `[]` | `0` / `0` ✅ |
| `average` (хоҳиши 4) | `average(["10", "20"])` | `510` ❌ |

Хулоса: ҷавобҳои воқеӣ **аксаран дурустанд**, ва ин дарс ҳам инро ростқавлона мегӯяд. Хато дар ҳолати «рақам дар шакли матн» пайдо мешавад (ҳамон мавзӯи дарси 8): `sum("25", 1)` → `251` ва `miyona(["10", "20"])` → `510`.
