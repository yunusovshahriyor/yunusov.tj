Ва як ҳолати маъмул: ёвар такроран ҳамон хаторо мекунад. Он гоҳ хоҳишро содда кунед: як қисми хурд, як саволи мушаххас. Ё худатон як сатрро бо console.log санҷед, ки қимат чист — ҳамон усули дарси ҳашт. Баъзан хато на дар код, балки дар он аст, ки чӣ мехоҳед: онро беҳтар навиштан кӯмак мекунад.

## 11:35 · Огоҳӣ: ба чӣ бовар накунед (≈40 сония)
**Тасвир:** чор корт: 🔑 «рамз, калид, маълумоти шахсӣ — нанависед» · 👻 «функсияи вуҷуднадошта» · 🕰️ «маълумоти кӯҳна» · 📋 «нусхаи бефаҳм — не».

Ва чанд огоҳӣ. Якум: ба зеҳни сунъӣ рамз, калид ва маълумоти шахсӣ нанависед — на рамзи ҳисоб, на рақами корт, на маълумоти дигарон. Он чизе, ки ба хидмати онлайн мефиристед, дигар танҳо дар дасти шумо нест.
Дуюм: баъзан ӯ чизеро «меофарад», ки вуҷуд надорад — функсия ё китобхонае, ки дар асл нест. Агар барнома мегӯяд, ки ном ёфт нашуд — дар ҳуҷҷатҳои расмӣ санҷед.
Саввум: маълумоти ӯ метавонад кӯҳна бошад. Ва чорум — ҳамон қоидаи дуюм: кодеро, ки намефаҳмед, нусха накунед.

## 12:15 · Барномасоз чӣ кор мекунад? (≈35 сония)
**Тасвир:** чор нишона дар атрофи одам: 🧩 масъаларо мефаҳмад · ✂️ ба қисмҳо тақсим мекунад · 🔍 санҷида мебинад · 🧠 масъулият мегирад; дар паҳлӯ — «ёвар: код, шарҳ, пешниҳод».

Ба ҳамин савол баргардем: барномасоз чӣ кор мекунад? Танҳо код навиштан нест. Аввал масъаларо мефаҳмад: одамон чӣ мехоҳанд. Баъд онро ба қисмҳои хурд тақсим мекунад — мисли дафтарчаи вазифаҳо. Баъд ҳар қисмро месанҷад. Ва масъулиятро ба души худ мегирад: ин барнома дуруст кор мекунад ё не.
Зеҳни сунъӣ аз ҳама бештар ба навиштани қисмҳо ва шарҳ додан кӯмак мекунад. Фаҳмидани масъала, тақсим кардан ва масъулият — бо шумост. Барои ҳамин он ёвар аст.

## 12:50 · Чӣ тавр бо зеҳни сунъӣ омӯхтан (≈55 сония)
**Тасвир:** тасма: 1 · худатон кӯшиш кунед → 2 · пурсед («чӣ мекунад?», «роҳи дигар?», «машқҳои монанд») → 3 · аз нав бо дасти худ нависед (на нусха); савол: «ман инро шарҳ дода метавонам?».

Ва охирон: чӣ тавр бо зеҳни сунъӣ омӯхтан, на танҳо кор кардан. Аввал худатон кӯшиш кунед: вазифаро худатон ҳал кунед, ҳатто агар хато шавад. Баъд пурсед: «Ин код чӣ мекунад?», «Роҳи дигар ҳаст?», «Ба ман машқҳои монанд деҳ».
Ва кодро аз нав бо дасти худ нависед, на нусха. Ҳамин тавр шумо ёд мегиред. Ҳамеша аз худ пурсед: ман ин ҷавобро шарҳ дода метавонам? Агар не — ҳанӯз кор мондааст.
Ҳар рӯз бист дақиқа — аз се соат дар як рӯзи ҳафта беҳтар аст. Як мавзӯъро бо зеҳни сунъӣ омӯзед, як вазифаро худатон ҳал кунед, як хаторо бо дасти худ ёбед. Пас аз як моҳ шумо худатон мебинед, ки чӣ тавр пеш рафтед.

## Вазифаҳои IDE (дарси `l13`, трекҳои JS) — барои иҷро пеш аз монтаж
1. **sum → матн:** функсияи `sum(a, b) { return a + b; }` (воқеан аз Claude); вазифа — ислоҳ, то `sum("25", 1)` → `26`. Санҷиш: `sum(25, 1)` → 26 ва `sum("25", 1)` → 26.
2. **miyona → матн:** `miyona(["10", "20"])` ҳоло `510` медиҳад; вазифа — ислоҳ, то `15` шавад; `[10, 20, 30]` → 20, `[]` → 0 бояд монад.
3. **double:** «ёвар» навишт `return n + 2` (хато). Санҷиш: `double(5)` → 10, `double(0)` → 0, `double(-3)` → -6.

## Код дар видео (ҷавобҳои воқеии Claude, санҷидашуда дар Node.js — `real-answers.md`)
```js
function sum(a, b) { return a + b; }                 // хоҳиши 1 (норавшан)
console.log(sum(2, 3));        // 5
console.log(sum("25", 1));     // 251  ← хато (дарси 8)

function add(a, b) { return Number(a) + Number(b); } // хоҳиши 2 (дақиқ)
console.log(add("25", 5));     // 30

function miyona(royhat) {                            // хоҳиши 3 (миёна, «ман навомӯзам»)
  if (royhat.length === 0) { return 0; }
  let jam = 0;
  for (const raqam of royhat) { jam += raqam; }
  return jam / royhat.length;
}
console.log(miyona([10, 20, 30]));     // 20
console.log(miyona([]));               // 0   (ёвар худаш ба назар гирифт)
console.log(miyona(["10", "20"]));     // 510 ← хато (матн пайваст мешавад)
// ислоҳ: jam += Number(raqam)  → miyona(["10", "20"]) = 15
// miyona() → TypeError: Cannot read properties of undefined (reading 'length')

function max(a, b) { if (a > b) { return a; } return b; }   // санҷиши охирин
console.log(max("9", "10"));                  // 9
console.log(max(Number("9"), Number("10")));  // 10
```
