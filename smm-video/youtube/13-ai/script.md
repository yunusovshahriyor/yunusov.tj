## 11:15 · Барномасоз чӣ кор мекунад? (≈40 сония)
**Тасвир:** чор нишона дар атрофи одам: 🧩 масъаларо мефаҳмад · ✂️ ба қисмҳо тақсим мекунад · 🔍 санҷида мебинад · 🧠 масъулият мегирад; дар паҳлӯ — «ёвар: код, шарҳ, пешниҳод».

Ба ҳамин савол баргардем: барномасоз чӣ кор мекунад? Танҳо код навиштан нест. Аввал масъаларо мефаҳмад: одамон чӣ мехоҳанд. Баъд онро ба қисмҳои хурд тақсим мекунад — мисли дафтарчаи вазифаҳо. Баъд ҳар қисмро месанҷад. Ва масъулиятро ба души худ мегирад: ин барнома дуруст кор мекунад ё не.
Зеҳни сунъӣ аз ҳама бештар ба навиштани қисмҳо ва шарҳ додан кӯмак мекунад. Фаҳмидани масъала, тақсим кардан ва масъулият — бо шумост. Барои ҳамин он ёвар аст.

## 11:55 · Чӣ тавр бо зеҳни сунъӣ омӯхтан (≈55 сония)
**Тасвир:** тасма: 1 · худатон кӯшиш кунед → 2 · пурсед («чӣ мекунад?», «роҳи дигар?», «машқҳои монанд») → 3 · аз нав бо дасти худ нависед (на нусха); савол: «ман инро шарҳ дода метавонам?».

Ва охирон: чӣ тавр бо зеҳни сунъӣ омӯхтан, на танҳо кор кардан. Аввал худатон кӯшиш кунед: вазифаро худатон ҳал кунед, ҳатто агар хато шавад. Баъд пурсед: «Ин код чӣ мекунад?», «Роҳи дигар ҳаст?», «Ба ман машқҳои монанд деҳ».
Ва кодро аз нав бо дасти худ нависед, на нусха. Ҳамин тавр шумо ёд мегиред. Ҳамеша аз худ пурсед: ман ин ҷавобро шарҳ дода метавонам? Агар не — ҳанӯз кор мондааст.
Ҳар рӯз бист дақиқа — аз се соат дар як рӯзи ҳафта беҳтар аст. Як мавзӯъро бо зеҳни сунъӣ омӯзед, як вазифаро худатон ҳал кунед, як хаторо бо дасти худ ёбед. Пас аз як моҳ шумо худатон мебинед, ки чӣ тавр пеш рафтед.

## 12:50 · Вазифаҳо ва санҷиш (≈70 сония)
**Тасвир:** IDE, дарси `l13`, 3 вазифа; сипас корт: `max("9", "10")` — «?» бо соат, «Пауза кунед».

Ва акнун вазифа барои шумо. Дар IDE дарси сенздаҳумро кушоед. Се вазифа ҳаст, ва ҳар се — кори ёвар, ки шумо бояд санҷед.
Якум: функсияи add бо матн хато медиҳад — ислоҳ кунед, то add аз «25» ва як бисту шаш диҳад. Дуюм: average бо рӯйхати холӣ NaN медиҳад — ислоҳ кунед, то нол диҳад. Саввум: ёвар функсияи double навишт — бояд ададро дучанд кунад. Санҷед: ҷавоб нодуруст аст. Хаторо ёбед ва ислоҳ кунед.
Ва санҷиши нав: функсияи max ду қимат мегирад ва калонашро бармегардонад. Консол лог, max аз «нӯҳ» ва «даҳ» — ҳарду дар қавсак, яъне матн. Чӣ чоп мешавад: нӯҳ ё даҳ? Видеоро пауза кунед ва фикр кунед.
…
Ҷавоб: нӯҳ! Матнҳо ҳарф ба ҳарф муқоиса мешаванд: «9» аз «1» калонтар аст. Бо Number ҳарду ба рақам табдил меёбанд — ва ҷавоб даҳ мешавад.

## 14:00 · Хулоса ва охири силсила (≈115 сония)
**Тасвир:** хулоса: «ёвар, на ҷонишин» + се қоида; тасмаи 13 дарс (13 нуқтаи сабз): тағйирёбанда · шарт · давр · рӯйхат · функсия · объект · дебаг · лоиҳа · HTML · CSS · JS · сайт · зеҳни сунъӣ; «Обуна шавед».

Хулоса мекунем. Зеҳни сунъӣ — ёвар, на ҷонишин. Се қоида: дақиқ пурсед, кодро хонед ва бифаҳмед, ҳатман иҷро кунед ва санҷед. Агар хато шуд — код, паёми хато ва интизориро нишон диҳед. Ва рамз ва маълумоти шахсиро нафиристед.
Ин охирин дарси силсилаи мост. Шумо аз тағйирёбанда то сайт ва зеҳни сунъӣ омадед: шарт, давр, рӯйхат, функсия, объект, дебаг, лоиҳа, HTML, CSS ва JavaScript. Акнун шумо мефаҳмед, ки код чӣ кор мекунад — ва ин асоси ҳама чиз аст. Қадами навбатӣ: лоиҳаи худатон.
Шпаргалкаи бепул дар тавсиф аст. Обуна шавед, то аз ҷаҳони барномасозӣ бехабар намонед.
Ва ҳоло — як бор ба роҳи тайкарда назар афканем. Дар дарси якум қуттии age-ро дидем — тағйирёбанда. Баъд шарт: ҳамеша ду роҳ. Баъд давр: як кор — бисёр бор. Баъд рӯйхат — қуттиҳо дар қафас. Функсия — як маротиба менависем, бисёр бор истифода мебарем. Объект — корти маълумот. Дебаг — хаторо ёфтан. Лоиҳа — ҳамаро якҷоя гирифтем. HTML, CSS, JavaScript — саҳифа. Ва дарси дувоздаҳум — чӣ тавр он ба одамон мерасад. Ҳар қадам ба қадами оянда такя мекард. Ва ҳоло — ёвар.
Ва дар хотир доред: ҳеҷ кас аз рӯзи аввал бе хато менависад. Хато — қисми роҳ аст. Ҳар хатое, ки худатон меёбед, аз ҳар ҷавоби тайёр беҳтар дар хотир мемонад. Барои ҳамин ин силсила бо вазифаҳо ва санҷишҳо буд — ҳамаи онҳо дар IDE ҳастанд.

## Вазифаҳои IDE (дарси `l13`, трекҳои JS) — барои иҷро пеш аз монтаж
1. **add:** функсияи `add(a, b) { return a + b; }` аз «ёвар»; вазифа — ислоҳ, то `add("25", 1)` → `26`. Санҷиш: `add(25, 1)` → 26 ва `add("25", 1)` → 26.
2. **average:** бо рӯйхати холӣ `NaN` медиҳад; вазифа — `[]` → `0`, `[10, 20, 30]` → `20`.
3. **double:** «ёвар» навишт `return n + 2` (хато). Санҷиш: `double(5)` → 10, `double(0)` → 0, `double(-3)` → -6.

## Код дар видео (санҷидашуда дар Node.js)
```js
function add(a, b) { return a + b; }
console.log(add(25, 1));      // 26
console.log(add("25", 1));    // 251  ← хато (дарси 8)
function add(a, b) { return Number(a) + Number(b); }
console.log(add("25", 1));    // 26

function average(list) {
  let sum = 0;
  for (let i = 0; i < list.length; i++) { sum = sum + list[i]; }
  return sum / list.length;
}
console.log(average([10, 20, 30]));   // 20
console.log(average([]));             // NaN  ← ҳолати холӣ
// ислоҳ: if (list.length === 0) { return 0; }   → 0
// average() → TypeError: Cannot read properties of undefined (reading 'length')

function max(a, b) { if (a > b) { return a; } return b; }
console.log(max("9", "10"));          // 9  (матн ҳарф ба ҳарф муқоиса мешавад)
console.log(max(Number("9"), Number("10")));   // 10
```
