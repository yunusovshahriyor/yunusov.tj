Салом, дӯстон! Тасаввур кунед, ки сад рақам нигоҳ доштан лозим аст. Оё сад тағйирёбанда месозем? Не — ин хаста мекунад.

## 0:24 · Рӯйхат чист? Образи рӯйхати харид (≈55 сония)
**Тасвир:** рӯйхати харид: нон, шир, тухм, себ, нок — панҷ қуттӣ дар як раф; болои ҳар кадом шумора: 0, 1, 2, 3, 4.

Тасаввур кунед, ки рӯйхати харид доред: нон, шир, тухм, себ, нок. Панҷ чиз дар як ҷой.
Дар барномасозӣ рӯйхат — ин тағйирёбандаест, ки дар дохилаш якчанд қимат дорад. Номаш array.
Ин ҳамон қуттии дарси якум аст, танҳо ин қуттӣ раф дорад: ҳар қимат ҷои худро дорад.
Ва ҳар ҷой шумора дорад. Диққат: шумора аз сифр оғоз мешавад! Нон — сифр, шир — як, тухм — ду. Ин аввал ғайриоддӣ менамояд, аммо ба он одат мекунед.
Дар ҳаёт рӯйхатҳо ҳама ҷо ҳастанд: рӯйхати мусиқӣ, суратҳо дар галерея, обуначиёни Instagram.

## 1:19 · Аввалин рӯйхат дар IDE (≈105 сония)
**Тасвир:** IDE, код ҳарф ба ҳарф; қутти `fruits` бо се ҷой; `fruits[0]` → себ; `fruits.length` → 3; тугмаи «▶ Иҷро».

Ба IDE мегузарем. Пайванд дар тавсиф аст, ҳамроҳи ман нависед.
Менависем: let fruits баробари, қавси чоркунҷа, се қимат: «себ», «нок», «ангур». Қиматҳо бо вергул ҷудо мешаванд, матн дар нохунак.
Барои гирифтани қимат — номи рӯйхат ва шумора дар қавси чоркунҷа. консол лог, fruits, қавси чоркунҷа, сифр. Иҷро. «Себ»! Ба ҷои як, шумораи сифр — аввалин қимат.
Ҳоло як: «нок». Ду: «ангур».
Ва агар донистан хоҳем, ки чанд қимат ҳаст? fruits нуқта length. Иҷро. Се!

## 3:04 · Илова кардан: push (≈50 сония)
**Тасвир:** рафи `fruits` бо се ҷой; қуттии нави «анор» ба ҷои чорум меафтад; `length` 3 → 4.

Ҳоло қимати нав илова мекунем. fruits нуқта push, дар қавс «анор». Ин «анор»-ро ба охири рӯйхат мегузорад.
Боз length. Иҷро. Чор! Рӯйхат калон шуд.
Донистан хуб аст: шумораи охирин ҳамеша length минус як аст. Дар мо чор қимат ҳаст, охирин — шумораи се.

## 3:56 · Рӯйхат ва давр (≈75 сония)
**Тасвир:** IDE: `for (let i = 0; i < fruits.length; i++)`; қуттии `i` 0 → 1 → 2 → 3 дар қатори рафи `fruits`; натиҷа: себ, нок, ангур, анор.

Рӯйхат ва давр — дӯстони наздик. Давр аз дарси се: for. Дар қавс: let i баробари сифр — оғоз аз сифр, зеро шумора аз сифр оғоз мешавад. Шарт: i хурд аз fruits нуқта length — то охири рӯйхат. Қадам: i плюс плюс.
Дар дохил: консол лог, fruits, дар қавси чоркунҷа i. Яъне ҳар бор i-и нав — қимати нав.
Иҷро. Себ, нок, ангур, анор. Ҳамаи қиматҳо як-як!
Дар рӯйхат ҳазор қимат бошад ҳам, ҳамин се сатр кифоя аст.

## 5:12 · Хатогиҳои маъмул (≈75 сония)
**Тасвир:** IDE бо хатоҳои сурх ва ишораҳои зард («💡»); дар кунҷ «Хатои 1 / 3» …

Се хатои маъмули рӯйхат.
Якум: шумораро аз як оғоз кардан. Дар рӯйхати се қимат fruits, қавси чоркунҷа, се — undefined, яъне «вуҷуд надорад». Охирин қимат дар шумораи ду аст, на се.
Дуюм: дар давр хурд ё баробар ба ҷои хурд. Агар нависем i хурд ё баробари fruits нуқта length, давр як қадами иловагӣ мекунад ва охирин сатр undefined мешавад. Диққат ба аломат!
Саввум: length-ро бо қавс навиштан. length — ин хосият, на фармон. Агар нависем fruits нуқта length бо қавс, хатои «is not a function» меояд. Қавс лозим нест.

## 6:27 · Вазифаҳо ва санҷиш (≈65 сония)

Ва акнун вазифа барои шумо. Дар IDE ҷадвали «чор, Рӯйхат»-ро кушоед. Се вазифа ҳаст.

IDE месанҷад ва мегӯяд, ки дуруст аст ё не.
Ва санҷиши нав: ҳамон рӯйхати харид — нон, шир, тухм, себ, нок. «Тухм» бо кадом шумора истодааст? Видеоро пауза кунед ва фикр кунед.

## Код дар видео (санҷидашуда)
```js
let fruits = ["себ", "нок", "ангур"];
console.log(fruits[0]);       // себ
console.log(fruits[1]);       // нок
console.log(fruits[2]);       // ангур
console.log(fruits.length);   // 3

fruits.push("анор");
console.log(fruits.length);   // 4
// охирин қимат: fruits[fruits.length - 1] → "анор"

for (let i = 0; i < fruits.length; i++) {
  console.log(fruits[i]);
}
// себ, нок, ангур, анор

// Хато 1: console.log(fruits[3]);  → undefined (дар рӯйхати 3 қимат)
// Хато 2: for (let i = 0; i <= fruits.length; i++) → дар охир undefined
// Хато 3: fruits.length()  → TypeError: fruits.length is not a function

// Санҷиш: ["нон", "шир", "тухм", "себ", "нок"][2] → "тухм"
```
