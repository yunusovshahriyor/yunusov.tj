## 0:00 · Хук (≈22 сония)
**Тасвир:** `let age = "25" + 1;` → терминал `251` бо нишонаи сурх; «26 интизор будем!»; «Чӣ тавр?». Дар кунҷ: «Дарси 8 · Хатогӣ ва дебаг».

Салом, дӯстон! Бисту панҷ плюс як — дусаду панҷоҳу як?! Мо бисту шаш интизор будем. Компютер хато накард — хато дар код аст.
Имрӯз мефаҳмем, ки чӣ тавр чунин хатоҳоро ёфтан мумкин аст. Ин дебаг аст. Дар охир санҷиши нав ҳаст. Оғоз мекунем!

## 0:24 · Баг ва механик (≈55 сония)
**Тасвир:** калима «БАГ» → «ДЕБАГ» (ёфтан + ислоҳ); мошин: чароғи хато → «бубин» → «санҷ» → «ислоҳ» — се нишона.

Хатои барномаро «баг» мегӯянд. Ёфтан ва ислоҳ кардани он — дебаг мебошад.
Тасаввур кунед, ки мошини шумо ҳаракат намекунад. Механик чӣ кор мекунад? Аввал мебинад, чӣ шуд. Баъд қисм ба қисм месанҷад — аккумулятор, сӯзишворӣ, чарх дар охир сабаби ҳаракат накардани мошинро пайдо карда онро таъмир мекунад.
Дар код ҳам ҳамин тавр. Се қадам: бубин, санҷ, ислоҳ кун.

## 1:20 · Қадами 1: бубин (≈55 сония)
**Тасвир:** IDE: `let age = "25" + 1;` / `console.log(age);` → `251`; ду корт: «Чӣ гирифтем — 251», «Чӣ мехостем — 26».

Ба IDE мегузарем. Пайванд дар тавсиф аст, ҳамроҳи ман нависед.
Менависем: let age баробари «бисту панҷ» дар нохунак плюс як. Консол лог, age. Иҷро. Дусаду панҷоҳу як!
Қадами якум — бубинед. Чӣ гирифтем? Дусаду панҷоҳу як. Чӣ мехостем? Бисту шаш. Фарқ — ҳамин ҷо хатост.
Диққат: паёми хато нест. Барнома кор кард — лекин нодуруст. Чунин хатоҳоро фақат худамон ёфта метавонем.

## 2:15 · Қадами 2: санҷ (≈70 сония)
**Тасвир:** IDE: `console.log(typeof age);` → `string`; қуттии `age` бо «25» (қуттии матнӣ, дарси 1); тир: «матн + рақам = часпонидан».

Қадами дуюм — санҷед. Мо мепурсем: age чӣ навъ аст? Консол лог, тайп-оф age. Иҷро. Стринг — яъне матн!
Чаро? Дар қавс «бисту панҷ» — матн аст, на рақам. Матн плюс рақам — компютер онҳоро часпонад: бисту панҷ ва як — дусаду панҷоҳу як. Ин ҳамон қуттии age аз дарси якум аст — матн ва рақам.
Маслиҳат: ҳангоми шубҳа — консол лог гузоред. Ин аввалин асбоби дебаг аст.

## 3:25 · Қадами 3: ислоҳ кун (≈45 сония)
**Тасвир:** IDE: `Number("25") + 1` → `26`; қуттии `age` рақамӣ; ✅.

Қадами сеюм — ислоҳ кунед. Намбер, дар қавс «бисту панҷ», плюс як. Намбер матнро ба рақам табдил медиҳад. Иҷро. Бисту шаш!
Ва акнун санҷед, ки дуруст шуд: баъд аз ислоҳ дубора иҷро кунед ва натиҷаро бо «чӣ мехостем» муқоиса кунед.

## 4:10 · Мисоли дуюм: функсия (≈75 сония)
**Тасвир:** IDE: `function average(a, b) { return a + b / 2; }`, `console.log(average(10, 20));` → `20` (мехостем 15); `console.log(20 / 2)` → `10`; `(a + b) / 2` → `15` ✅. Қадамҳо: 1·2·3 дар кунҷ.

Мисоли дуюм — функсия аз дарси панҷум. Мо мехоҳем миёнаи ду рақамро ёбем: фанкшн эверейҷ, a ва b. Риторн: a плюс b тақсим ба ду.
Даъват: эверейҷ даҳ ва бист. Мо понздаҳ интизор будем. Иҷро — бист!
Қадами якум: бубинед. Бист гирифтем, понздаҳ мехостем. Қадами дуюм: санҷед. Консол лог, b тақсим ба ду — даҳ. Мефаҳмем: тақсим пеш аз плюс иҷро мешавад. Компютер даҳ ва бистро ҷамъ накард, бист-ро ду бахш кард ва ба даҳ ҷамъ кард.
Қадами сеюм: қавс. Дар қавс a плюс b, баъд тақсим ба ду. Иҷро — понздаҳ!
Ҳамин тавр: аввал мебинем, баъд бо консол лог меёбем, баъд ислоҳ мекунем.

## 5:25 · Вазифаҳо ва санҷиш (≈85 сония)
**Тасвир:** IDE (ҷадвали «✏️ Озод»): се вазифа бо кодҳои хатодор: `price + 20`, `sum + i`, `a + b / 2` — рақами 1·2·3; сипас корти `"10" + 5`, «?» бо соат, «Пауза кунед».

Ва акнун вазифа барои шумо. Дар IDE ҷадвали «Озод»-ро кушоед. Се барномаи хатодор ҳаст — кодҳо дар тавсиф аст. Дар ҳар кадом се қадамро иҷро кунед: бубинед, санҷед, ислоҳ кунед.
Якум: нарх ба «сад» дар нохунак, плюс бист. Бояд сад ва бист шавад. Дуюм: давр, ки ҷамъро ҳисоб мекунад, вале сифр мебарорад. Саввум: ҳамон эверейҷ — бо қавс.
Ва санҷиши нав: консол лог, «даҳ» дар нохунак плюс панҷ. Чӣ чоп мекунад? Ёдовар: «даҳ» дар нохунак — матн аст. Видеоро пауза кунед ва фикр кунед.
…
Ҷавоб: саду панҷ. Матн плюс рақам — часпонида мешавад, ҷамъ нашуд. Агар мехоҳед ҷамъ шавад — намбер, даҳ плюс панҷ — понздаҳ.

## 6:50 · Хулоса ва даъват (≈35 сония)
**Тасвир:** корти «ДЕБАГ = бубин · санҷ · ислоҳ кун»; корти «Дарси 9: Лоиҳаи хурд — рӯйхати вазифаҳо».

Хулоса мекунем. Дебаг — се қадам: бубин, санҷ, ислоҳ кун. Бубин — чӣ гирифтем ва чӣ мехостем. Санҷ — бо консол лог. Ислоҳ — як чиз ва санҷиши дубора.
Хатогиҳо дар код ин роҳи фаҳмиш ва омӯзиш аст. Шпаргалкаи бепул бо ҳамаи ин мисолҳо дар тавсиф аст.
Дарси оянда — лоиҳаи хурд: рӯйхати вазифаҳо. Обуна шавед, то аз ҷаҳони барномасозӣ бехабар намонед.

## Код (санҷидашуда дар Node.js)
```js
// Қадами 1–3
let age = "25" + 1;
console.log(age);                  // 251  (мехостем 26)
console.log(typeof age);           // string — матн!
console.log(Number("25") + 1);     // 26

// Мисоли дуюм
function average(a, b) { return a + b / 2; }
console.log(average(10, 20));      // 20  (мехостем 15)
console.log(20 / 2);               // 10  — санҷиш
function average(a, b) { return (a + b) / 2; }
console.log(average(10, 20));      // 15

// Санҷиш
console.log("10" + 5);             // 105
console.log(Number("10") + 5);     // 15
```
