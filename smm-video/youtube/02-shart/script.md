## 0:00 · Хук (≈20 сония)
**Тасвир:** аломати савол, ду тир: ✓ сабз ва ✗ сурх. Қуттии `age` бо 15, дар паҳлӯ «Хуш омадед?». Дар кунҷ: «Дарси 2 · Шарт».

Салом, дӯстон! Шумо ҳар рӯз садҳо қарор қабул мекунед: борон борад — чатр мегиред, нарх қимат бошад — намехаред. Ҳар барнома ҳам ҳамин тавр кор мекунад.
Дар ин видео мефаҳмед, ки чӣ тавр компютерро ба қарор қабул кардан водор мекунем. Дар охир як санҷиши ҷиддӣ ҳаст, ки дар сторис ваъда дода будам. Оғоз мекунем!

## 0:20 · Шарт чист? Образи субҳ (≈55 сония)
**Тасвир:** тиреза: абр ва борон → чатр; офтоб → айнаки офтобӣ. Тамғаҳо: «if = агар», «else = вагарна».

Аз хона мебароед. Агар борон борад — чатр мегиред. Вагарна — айнаки офтобӣ мегиред.
Ана ҳамин шарт аст. Шарт — ин савол ва ду роҳ. Савол: борон меборад? Агар ҳа — як кор, вагарна — кори дигар.
Дар барномасозӣ ду калима дорем: if — «агар» ва else — «вагарна». Ҳамааш ҳамин. Танҳо ба забони англисӣ.

## 1:15 · Аввалин шарт дар IDE (≈100 сония)
**Тасвир:** IDE, код ҳарф ба ҳарф чоп мешавад; `age >= 18` ҷудо мешавад; тугмаи «▶ Иҷро»; натиҷа дар поён.

Ба IDE мегузарем. Пайванд дар тавсиф аст, ҳамроҳи ман нависед.
Қуттии age-ро аз дарси гузашта ба ёд меоред? Менависем: let age баробари бисту панҷ.
Акнун шарт: if, дар қавс age калон ё баробари ҳаждаҳ. Яъне синну сол аз ҳаждаҳ кам нест. Баъд қавси фигурӣ, ва дохилаш: console.log, «Хуш омадед!».
Баъд else, боз қавси фигурӣ: console.log, «Ҳанӯз барвақт».
Иҷро мекунем. Натиҷа: «Хуш омадед!». Чаро? Компютер санҷид: бисту панҷ аз ҳаждаҳ калон аст? Ҳа. Пас роҳи якум.
Ҳоло age-ро ба понздаҳ иваз мекунем. Иҷро. «Ҳанӯз барвақт». Компютер санҷид, ҷавоб «не» шуд, ва ба роҳи else рафт. Код ҳамон, танҳо қимат дигар — ва қарор дигар.
Қоидаро дар хотир доред: дар қавс — савол, дар қавси фигурӣ — коре, ки ҳангоми ҷавоби «ҳа» ё «не» иҷро мешавад.

## 2:55 · Аломатҳои муқоиса (≈75 сония)
**Тасвир:** ҷадвал дар IDE ё дар экран: `>`, `<`, `>=`, `<=`, `===`, ҳар кадом бо мисол ва натиҷаи true / false.

Барои савол додан аломатҳо лозиманд. Панҷтояшро мебинем.
Калон: аз ҳаждаҳ калон. Хурд: аз ҳаждаҳ хурд. Калон ё баробар — ин ҳамон аст, ки мо навиштем. Хурд ё баробар. Ва се баробарӣ — яъне «айнан баробар аст?».
Диққат ба фарқи калон ва калон ё баробар. Агар age баробари ҳаждаҳ бошад: «калон»-и ҳаждаҳ — не, ҳаждаҳ аз ҳаждаҳ калон нест. Аммо «калон ё баробар» — ҳа. Барои ҳамин шарти мо ҳаждаҳсолаҳоро ҳам мегузаронад.
Ҷавоби ҳар муқоиса ҳамеша ҳа ё не аст — ҳамон true ва false-и дарси гузашта. Ҳамин ҷавоб қарорро муайян мекунад.

## 3:55 · Шарт дар ҳаёт ва се роҳ (≈70 сония)
**Тасвир:** светофор (сабз → «Гузаред», сурх → «Биистед»); майдони парол (✓ / ✗); сипас дарахти қарори се шоха: гарм / мӯътадил / хунук.

Шарт дар ҳама ҷо ҳаст. Светофор сабз бошад — мегузарем, вагарна меистем. Парол дуруст бошад — ворид мешавед, нодуруст бошад — хато. Барои парол се баробарӣ истифода мебарем: if pass се баробар «1234».
Гоҳо ду роҳ кам аст. Масалан, ҳарорат. Агар аз сӣ зиёд бошад — «Гарм». Вагарна агар аз понздаҳ зиёд бошад — «Мӯътадил». Вагарна — «Хунук».
Дар код: if, баъд else if, баъд else. Роҳҳо аз боло ба поён санҷида мешаванд ва аввалин «ҳа» интихоб мешавад. Се-чор роҳ ҳам метавонад бошад.

## 4:55 · Хатогиҳои маъмул (≈75 сония)
**Тасвир:** IDE бо хатоҳои сурх ва ишораҳои зард («💡»); сатри дуруст сабз.

Се хатои маъмули шарт.
Якум: як баробарӣ ба ҷои се. Агар нависед if, дар қавс age баробари ҳаждаҳ, як аломат — ин савол нест, ин «гузор»! Компютер ба age ҳаждаҳро мегузорад ва шарт ҳамеша «ҳа» мешавад. Барои савол — се баробарӣ. Як баробарӣ — барои гузоштани қимат.
Дуюм: матн ва рақам ба ҳам намеоянд. Панҷ ва «панҷ» дар нохунак — се баробарӣ мегӯяд: ин ҳамон нест, чунки яке рақам, дигаре матн. Дарси гузашта дидем: нохунак навъро иваз мекунад.
Саввум: фаромӯш кардани қавси фигурӣ ё қавс. IDE хаторо ба тоҷикӣ шарҳ медиҳад ва сатрро нишон медиҳад. Ҳамеша аввал хабарро хонед.

## 6:10 · Вазифаҳо ва санҷиши ваъдашуда (≈55 сония)
**Тасвир:** саҳифаи «2 · Шарт» дар IDE, вазифаи 1 ва 2, тугмаи «✅ Санҷиш»; сипас қуттии `age` бо 15, аломати савол, «Пауза кунед».

Акнун вазифа барои шумо. Дар IDE ҷадвали «2 · Шарт»-ро кушоед. Ду вазифа ҳаст.
Якум: ҳарорат. Агар temperature аз сӣ зиёд бошад — «Гарм аст», вагарна — «Хунук аст».
Дуюм: даромадан. Агар age калон ё баробари ҳаждаҳ бошад — «Хуш омадед!», вагарна — «Ҳанӯз барвақт». IDE бо якчанд қимат месанҷад ва мегӯяд, ки дуруст аст ё не.
Ва ҳамон санҷиши ваъдашуда: age баробари понздаҳ аст. Барнома чӣ мегӯяд? Видеоро пауза кунед ва фикр кунед.
…
Ҷавоб: «Ҳанӯз барвақт». Понздаҳ аз ҳаждаҳ хурд аст, шарт «не» мешавад, ва барнома ба else меравад.

## 6:55 · Хулоса ва даъват (≈40 сония)
**Тасвир:** хулоса: «Шарт = савол + ду роҳ»; `if` / `else if` / `else`; `>` `<` `>=` `<=` `===`; корти «Дарси 3: Давр (loop)».

Хулоса мекунем. Шарт — савол ва ду роҳ. if — агар, else — вагарна, else if — роҳи иловагӣ. Барои савол — аломатҳои муқоиса, ва барои баробарӣ — се баробарӣ, на як.
Шпаргалкаи бепул бо ҳамаи ин мисолҳо дар тавсиф аст.
Дарси оянда — давр, loop: чӣ тавр як кореро сад маротиба бе такрор навиштан мумкин аст. Обуна шавед, то аз ҷаҳони барномасозӣ бехабар намонед.

## Код дар видео (санҷидашуда)
```js
let age = 25;

if (age >= 18) {
  console.log("Хуш омадед!");
} else {
  console.log("Ҳанӯз барвақт");
}
// age = 25 → «Хуш омадед!»; age = 15 → «Ҳанӯз барвақт»; age = 18 → «Хуш омадед!»

let temperature = 20;

if (temperature > 30) {
  console.log("Гарм");
} else if (temperature > 15) {
  console.log("Мӯътадил");
} else {
  console.log("Хунук");
}
// 35 → «Гарм», 20 → «Мӯътадил», 5 → «Хунук»

let pass = "1234";

if (pass === "1234") {
  console.log("Ворид шудед");
} else {
  console.log("Парол нодуруст");
}

// Хато: if (age = 18) — ин гузоштан аст (age мешавад 18), на муқоиса
// 5 === "5" → false (рақам ≠ матн)
```
