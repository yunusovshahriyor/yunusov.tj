# YouTube · Дарси 1: «Тағйирёбанда» (variable) — сенарияи пурра

Формат: 16:9 (1920×1080), ~8–9 дақиқа. Суръати хониш: табиӣ (бе тезонидан), паузаи кӯтоҳ байни қисмҳо.
Овоз: клони «Шаҳриёр — Студия WAV» (v4). Услуби тасвир: ҳамон услуби роликҳо (коғаз, бирюзаӣ, зангзада).
Ҳамаи мисолҳои код дар JavaScript санҷида шудаанд.

---

## 0:00 · Хук (≈20 сония)
**Тасвир:** қуттии `age` бо рақами 25, рақам ба 26 иваз мешавад; дар кунҷ: «Дарси 1 · Тағйирёбанда».

Салом, дӯстон! Дар ин видео мо як мафҳумро мефаҳмем, ки ҳар барнома аз он оғоз мешавад — тағйирёбанда.
Баъд аз ин видео шумо худатон аввалин коди худро менависед, онро иҷро мекунед ва мефаҳмед, ки чаро баъзан барнома хато медиҳад.
Ҳеҷ чиз насб кардан лозим нест. Танҳо браузер. Оғоз мекунем!

## 0:20 · Тағйирёбанда чист? Образи қуттӣ (≈70 сония)
**Тасвир:** қуттии картонӣ, тамға «age», рақам дар дохили он. Анимация: 25 → 26.

Тасаввур кунед, ки як қуттӣ доред. Болои қуттӣ тамға мечаспонед ва ном менависед, масалан «age», яъне синну сол. Ва дар дохили қуттӣ рақами бисту панҷро мегузоред.
Ана ҳамин тағйирёбанда аст. Ду чиз дорад: ном — он чизест, ки болои қуттӣ навиштаем, ва қимат — он чизест, ки дар дохили қуттӣ мемонад.
Як сол мегузарад. Мо рақами кӯҳнаро мебарорем ва бисту шашро мегузорем. Қуттӣ ҳамон, ном ҳамон, танҳо қимат иваз шуд. Барои ҳамин онро «тағйирёбанда» мегӯянд: чизе, ки тағйир меёбад.
Дар ҳаёт ҳам чунин қуттиҳо зиёданд: холи бозӣ, бақияи ҳисоби бонк, шумораи пайравонатон дар Instagram. Ҳамаи инҳо тағйирёбанда ҳастанд.

## 1:30 · Аввалин код дар IDE (≈90 сония)
**Тасвир:** намоиши мини-IDE: сатр ба сатр чоп мешавад, тугмаи «▶ Иҷро», натиҷа дар поён.

Акнун ба амал мегузарем. Ман мини-IDE-ро кушодам: пайванд дар тавсифи видео аст. Шумо ҳам онро кушоед ва бо ман ҳамроҳ нависед.
Менависем: let age = 25. «let» — ин ҳамон «қуттии нав месозам» аст. «age» — ном. Аломати баробар — «дар дохилаш гузор». Ва бисту панҷ — қимат. Охирин нуқтавергул.
Акнун нишон медиҳем: console.log, дар қавс age. console.log — ин «ба экран нишон деҳ» аст.
Пахш мекунем «Иҷро». Дар натиҷа: бисту панҷ.
Қимати навро мегузорем: age = 26. Диққат: акнун «let» нест, чунки қуттӣ аллакай ҳаст, мо танҳо қиматро иваз мекунем. Боз console.log. Иҷро. Бисту шаш!
Шумо ҳам кӯшиш кунед: рақамро ба сад иваз кунед ва бубинед, ки чӣ мешавад.

## 3:00 · Се навъи қимат (≈90 сония)
**Тасвир:** се қуттӣ: «26», «Салом», «true» бо тамғаи number / string / boolean.

Дар қуттӣ на танҳо рақам, балки навъҳои дигар ҳам гузоштан мумкин аст. Се навъи асосиро мебинем.
Якум — рақам. Масалан, бисту шаш. Бо рақам ҳисоб кардан мумкин: нарх ҳамроҳи миқдор — як нарх даҳ, се дона, ҷамъ сӣ.
Дуюм — матн. Матн ҳамеша дар нохунак меояд: «Шаҳриёр». Матнҳоро бо плюс якҷоя кардан мумкин: «Салом, » плюс name плюс «!» мешавад «Салом, Шаҳриёр!».
Саввум — ҳа ё не, яъне true ва false. Масалан, isStudent баробари true — «донишҷӯ ҳастам».
Ва як хусусияти аҷиб: рақами «5» дар нохунак — ин аллакай матн аст! Агар «5» плюс 1 нависем, натиҷа на шаш, балки «панҷоҳу як», яъне матни «51». Нохунак навъро иваз мекунад.

## 4:30 · let ва const (≈60 сония)
**Тасвир:** ду қуттӣ: бо қулф (const) ва бе қулф (let).

Ду хел қуттӣ ҳаст. let — қуттии одӣ: қиматро иваз кардан мумкин. const — қуттии қуфлшуда: қимат доимист. Масалан, const pi баробари се ва чордаҳ. Ин рақам иваз намешавад.
Қоидаи оддӣ: агар қимат тағйир наёбад — const нависед. Агар тағйир меёбад, масалан холи бозӣ — let.

## 5:30 · Хатогиҳои маъмул (≈70 сония)
**Тасвир:** IDE бо хатоҳои сурх ва ишораҳои зард («💡»).

Ҳама хато мекунанд, ва ин муқаррарӣ аст. Се хатои маъмулро мебинем.
Якум: const-ро иваз кардан. Менависем const pi баробари 3.14, баъд pi баробари 3. Хато: «Assignment to constant variable» — «const-ро иваз кардан мумкин нест». Ҳал: let истифода баред.
Дуюм: ном бо рақам оғоз шуда наметавонад. let 2age — хатои навиштан. Номро бо ҳарф оғоз кунед: age2.
Саввум: let-ро ду бор нависед. let a баробари як, баъд боз let a баробари ду. Хато: «Identifier a has already been declared» — «ин ном аллакай ҳаст». Дубора let лозим нест, танҳо қиматро иваз кунед.
Хуб аст, ки IDE ҳар хаторо ба тоҷикӣ шарҳ медиҳад ва нишон медиҳад, дар кадом сатр хато шудааст.

## 6:40 · Вазифаҳо (≈60 сония)
**Тасвир:** саҳифаи «1 · Тағйирёбанда» дар IDE, вазифаи 1 ва 2, тугмаи «✅ Санҷиш».

Ва акнун вазифа барои шумо. Дар IDE ҷадвали «1 · Тағйирёбанда»-ро кушоед. Ду вазифа ҳаст.
Якум: тағйирёбандаи age-ро бо қимати бисту панҷ созед, ба бисту шаш иваз кунед ва нишон диҳед.
Дуюум: тағйирёбандаи name-ро бо номи худ созед ва нависед «Салом, ном!».
Баъд тугмаи «Санҷиш»-ро пахш кунед. IDE мегӯяд, ки ҳамааш дуруст аст ё не. Агар мушкил шуд, тугмаи «Кӯмак» ҳаст.
Видеоро пауза кунед ва кӯшиш кунед. Ман интизор мешавам.

## 7:40 · Хулоса ва даъват (≈40 сония)
**Тасвир:** хулоса: «Тағйирёбанда = ном + қимат», се навъ, let / const.

Хулоса мекунем. Тағйирёбанда — қуттӣ бо ном ва қимат. Қиматро иваз кардан мумкин. Се навъи асосӣ: рақам, матн, ҳа ё не. let — барои қиматҳое, ки иваз мешаванд, const — барои доимиҳо.
Шпаргалкаи бепул бо ҳамаи ин мисолҳо ва ҷавобҳо дар тавсиф ё дар Instagram аст: дар шарҳи ролик «РӮЙХАТ» нависед.
Дарси оянда — шарт, if ва else: чӣ тавр барнома қарор қабул мекунад. Агар видео ба шумо ёрӣ дод, обуна шавед ва пайвандро ба дӯсте фиристед, ки барномасозиро мехоҳад.
То дидори нав!
