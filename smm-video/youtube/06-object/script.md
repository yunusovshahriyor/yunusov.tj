# YouTube · Дарси 6: «Объект» (object) — сенарияи пурра

Формат: 16:9 (1920×1080), ~6,5 дақиқа. Суръати хониш: табиӣ, ором, паузаи кӯтоҳ байни қисмҳо.
Овоз: «Шаҳриёр — Студия WAV» (`eleven_v4`, `tg`). Услуби тасвир: «VS Code Dark + бунафш» (`brand/STYLE.md`); код ҳамеша дар IDE-и худамон. Бе субтитр ва бе хати пешрафт дар видео.
Қаҳрамон: «корти шиноснома» (ном, синну сол, шаҳр). Пайвастагӣ: дарси 1 (қуттӣ), дарси 3 (давр), дарси 4 (рӯйхат).
Ҳамаи мисолҳои код дар JavaScript (Node) санҷида шудаанд.
Вақтҳо тахминианд; чаптерҳои ниҳоӣ аз вақти воқеии видео гирифта мешаванд.

## 0:00 · Хук (≈22 сония)
**Тасвир:** се тағйирёбанда `name1`, `age1`, `city1` … чандин қуттӣ — хато; як корт бо се сатр — дуруст. Дар кунҷ: «Дарси 6 · Объект».

Салом, дӯстон! Тасаввур кунед, ки дар барнома маълумоти як одам лозим аст: ном, синну сол, шаҳр. Оё се тағйирёбанда месозем? Ва барои ҳар одами дигар — боз се? Хаста мешавем.
Як корт кифоя аст! Ин объект аст. Дар охир санҷиши нав ҳаст. Оғоз мекунем!

## 0:24 · Объект чист? Образи корт (≈55 сония)
**Тасвир:** корти шиноснома: «ном — Нигина», «синну сол — 20», «шаҳр — Душанбе»; бо тирчаҳо: калид → қимат. Муқоиса: рӯйхат (шумора) ва объект (ном).

Тасаввур кунед, ки корти шиноснома дошта бошед: дар он ном, синну сол ва шаҳр навишта шудааст. Ҳар хат ном дорад, ва дар паҳлӯяш қимат.
Объект ҳамин аст: корт, ки якчанд хусусият дорад. Ҳар хусусият ном дорад — калид, ва қимат.
Аз дарси чорум фарқ: дар рӯйхат қиматҳоро бо шумора мегирифтем — сифр, як, ду. Дар объект — бо ном: ном, синну сол.
Дар ҳаёт ҳам объектҳо ҳама ҷо ҳастанд: профили Instagram, корти маҳсулот дар дукон, пайванди мусиқӣ.

## 1:20 · Аввалин объект дар IDE (≈90 сония)
**Тасвир:** IDE, код ҳарф ба ҳарф; қавси фигурӣ, калид: қимат; `person.name` → Нигина; `person.age` → 20.

Ба IDE мегузарем. Пайванд дар тавсиф аст, ҳамроҳи ман нависед.
Менависем: let person баробари, қавси фигурӣ. Дар дохил: name, ду нуқта, «Нигина». Вергул. age, ду нуқта, бисту. Қавси ёпӣ ва нуқтавергул.
Ин ҳамон қуттии дарси якум аст, танҳо дар дохилаш якчанд хусусият.
Барои гирифтани қимат — номи объект, нуқта ва номи хусусият. консол лог, person нуқта name. Иҷро. «Нигина»! Ва person нуқта age — бисту.
Нуқта — ин «дар дохили ин корт».

## 2:50 · Иваз кардан ва илова кардан (≈65 сония)
**Тасвир:** IDE: `person.age = person.age + 1` → 21; `person.city = "Душанбе"` — хусусияти нав; корт бо се сатр.

Ҳоло қиматро иваз мекунем. person нуқта age баробари person нуқта age плюс як. Яъне ба синну сол як илова мекунем. Иҷро. Бисту як!
Ва хусусияти нав илова мекунем: person нуқта city баробари «Душанбе». Нуқта, ном ва қимат — ҳамааш. Консол лог, person нуқта city. Иҷро. «Душанбе»!
Корт калон шуд: ном, синну сол ва шаҳр.

## 3:55 · Рӯйхати объектҳо (≈75 сония)
**Тасвир:** IDE: `people = [ {…}, {…} ]`; `people[1].name` → «Фарҳод»; давр: ном як-як. Нишона: «дарси 3» ва «дарси 4».

Агар бисёр одам бошад? Рӯйхати объектҳо — аз дарси чорум. let people баробари қавси чоркунҷа: ду корт, Нигина бисту ва Фарҳод бисту панҷ.
Барои гирифтани номи дуюм: people, қавси чоркунҷа, як — ин корти дуюм. Нуқта name. Иҷро. «Фарҳод»! Шумора аз сифр оғоз мешавад — мисли пештара.
Ва давр аз дарси сеюм: for, let i баробари сифр, i хурд аз people нуқта length, i плюс плюс. Консол лог, people, i, нуқта name. Иҷро. Нигина, Фарҳод. Ҳамаи номҳо як-як!
Дар барномаҳои воқеӣ ҳамин тавр кор мекунанд: рӯйхати корт.

## 5:10 · Хатогиҳои маъмул (≈70 сония)
**Тасвир:** IDE бо хатоҳои сурх ва ишораҳои зард («💡»); дар кунҷ «Хатои 1 / 3» …

Се хатои маъмули объект.
Якум: ном дар хусусият нодуруст. Агар нависем person нуқта nmae, ҳарфҳо ҷой иваз шуданд — ҷавоб undefined, яъне «вуҷуд надорад». Диққат ба имло!
Дуюм: матнро бе нохунак навиштан. name, ду нуқта, Нигина бе нохунак — хатои «Нигина is not defined». Матн ҳамеша дар нохунак аст.
Саввум: вергулро фаромӯш кардан. Агар байни name ва age вергул набошад, хатои «Unexpected identifier». Хусусиятҳо бо вергул ҷудо мешаванд.

## 6:25 · Вазифаҳо ва санҷиш (≈65 сония)
**Тасвир:** саҳифаи «6 · Объект» дар IDE, вазифаи 1, 2, 3, тугмаи «✅ Санҷиш»; сипас корт `person` бо age = 20, «?» бо соат, «Пауза кунед».

Ва акнун вазифа барои шумо. Дар IDE ҷадвали «шаш, Объект»-ро кушоед. Се вазифа ҳаст.
Якум: объекти person созед — name «Нигина», age бисту. Дуюм: синну солро як зиёд кунед, бояд бисту як шавад. Саввум: хусусияти city илова кунед бо қимати «Душанбе».
IDE месанҷад ва мегӯяд, ки дуруст аст ё не.
Ва санҷиши нав: person дорад name «Нигина» ва age бисту. Мо менависем: person нуқта age баробари person нуқта age плюс як. Ва консол лог, person нуқта age зарби ду. Чӣ мешавад? Видеоро пауза кунед ва фикр кунед.
…
Ҷавоб: чил ва ду. Аввал синну сол мешавад бисту як. Баъд бисту як зарби ду — чил ва ду.

## 7:30 · Хулоса ва даъват (≈35 сония)
**Тасвир:** хулоса: «Объект = калид + қимат»; `person.name`, `person.age = 21`; корти «Дарси 7: Хатогиро ёб (дебаг)».

Хулоса мекунем. Объект — корт бо якчанд хусусият: калид ва қимат. Қиматро бо нуқта мегирем ва иваз мекунем. Хусусияти нав ҳам илова кардан мумкин аст. Ва объектҳоро метавон дар рӯйхат нигоҳ дошт.
Шпаргалкаи бепул бо ҳамаи ин мисолҳо дар тавсиф аст.
Дарси оянда — дебаг: чӣ тавр хатоҳоро худамон меёбем. Обуна шавед, то аз ҷаҳони барномасозӣ бехабар намонед.

## Код дар видео (санҷидашуда)
```js
let person = { name: "Нигина", age: 20 };
console.log(person.name);   // Нигина
console.log(person.age);    // 20

person.age = person.age + 1;
console.log(person.age);    // 21

person.city = "Душанбе";
console.log(person.city);   // Душанбе

let people = [{ name: "Нигина", age: 20 }, { name: "Фарҳод", age: 25 }];
console.log(people[1].name);   // Фарҳод
for (let i = 0; i < people.length; i++) {
  console.log(people[i].name);   // Нигина, Фарҳод
}

// Хато 1: console.log(person.nmae);   → undefined
// Хато 2: let p = { name: Нигина };   → ReferenceError: Нигина is not defined
// Хато 3: let p = { name: "Нигина" age: 20 };   → SyntaxError: Unexpected identifier 'age'

// Санҷиш:
// person.age = person.age + 1;
// console.log(person.age * 2);   // 42
```
