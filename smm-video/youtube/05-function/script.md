## 0:00 · Хук (≈22 сония)
**Тасвир:** як сатр код 5 бор нусха мешавад («Салом, Нигина!», «Салом, Фарҳод!», «Салом, Зарина!»…) → як қуттии «greet» бо тугмаи «▶». Дар кунҷ: «Дарси 5 · Функсия».

Салом, дӯстон! Тасаввур кунед, ки як кореро бисёр бор такрор кардан лозим аст: масалан, ба ҳар кас бо номаш салом гуфтан. Оё ҳар дафъа ҳамон кодро нусха мекунем? Не.
Як маротиба менависем — ва бисёр бор истифода мебарем. Ин функсия аст. Дар охир санҷиши нав ҳаст. Оғоз мекунем!

## 0:24 · Функсия чист? Образи рецепт (≈55 сония)
**Тасвир:** рецепти палав: ҷузъҳо (биринҷ, гӯшт, сабзӣ) → «пухтан» → палав; ҳамон тавр: вуруд → функсия → баромад.

Тасаввур кунед, ки рецепти палав доред. Рецептро як маротиба менависем. Баъд ҳар вақт, ки палав мепазем, ҳамон рецептро истифода мебарем.
Рецепт се чиз дорад: ном, ҷузъҳо ва натиҷа. Ҷузъҳоро медиҳем — рецепт кор мекунад — натиҷа мебарояд.
Функсия ҳам ҳамин тавр: ном дорад, ҷузъҳо мегирад — онҳоро «вуруд» мегӯем — ва натиҷа бармегардонад.
Яке аз мисолҳои оддӣ: калкулятор. Рақам медиҳем, тугмаи «ду баробар» — натиҷа.

## 1:19 · Аввалин функсия дар IDE (≈75 сония)
**Тасвир:** IDE, код ҳарф ба ҳарф; `function`, ном, қавс, `{ }`; тугмаи «▶ Иҷро»; даъват 3 бор.

Ба IDE мегузарем. Пайванд дар тавсиф аст, ҳамроҳи ман нависед.
Менависем: function, ном — sayHello, қавс. Дар қавсҳои фигурӣ: консол лог, «Салом!».
Иҷро мекунем. Ҳеҷ чиз нашуд! Чаро? Мо рецептро навиштем, аммо онро истифода набурдем.
Функсияро даъват мекунем: sayHello бо қавс. Иҷро. «Салом!». Ду бор нависем — ду бор. Се бор — се бор.
Қоида: навиштан — як бор, даъват — ҳар қадар хоҳем.

## 2:34 · Параметр: функсия бо вуруд (≈65 сония)
**Тасвир:** IDE: `greet(name)`; қуттии `name` (дарси 1) дар қавс; «Нигина» → «Салом, Нигина!»; «Фарҳод» → «Салом, Фарҳод!».

Ҳоло вуруд илова мекунем. Дар қавс ном менависем — name. Ин параметр аст: қуттӣ, ки ҳангоми даъват қиматро мегирад. Ҳамон қуттии name аз дарси якум!
Дар дохил: консол лог, «Салом, » плюс name плюс «!». Матнҳоро бо плюс ҷамъ мекунем — аз дарси якум.
Даъват: greet, дар қавс «Нигина». Иҷро. «Салом, Нигина!». Ва greet, «Фарҳод». «Салом, Фарҳод!».
Код як, натиҷа гуногун. Ана қуввати функсия.

## 3:39 · return: ҷавоб бармегардонем (≈75 сония)
**Тасвир:** IDE: `function double(x) { return x * 2; }`; `console.log(double(5))` → 10; `let result = double(4)` → 8; `result + 1` → 9. Тасвир: тирчаи «return» аз функсия ба берун.

Баъзан функсия бояд на нишон диҳад, балки ҷавоб баргардонад. Барои ин return аст.
Менависем: function double, дар қавс x. Дар дохил: return x плюс-не, x зарби ду.
Даъват: консол лог, double, дар қавс панҷ. Иҷро. Даҳ!
Return — ҷавоб ба ҷое, ки функсияро даъват кардем. Мо метавонем ҷавобро дар қуттӣ нигоҳ дорем: let result баробари double, чор. Ва истифода барем: result плюс як — нӯҳ.
Фарқ: console.log — нишон медиҳад, return — баргардонад.

## 4:54 · Функсия бо шарт: isAdult (≈45 сония)
**Тасвир:** IDE: `function isAdult(age) { return age >= 18; }`; `isAdult(20)`, `isAdult(18)`, `isAdult(17)` → true true false. Нишона: «дарси 2».

Функсия бо шарт аз дарси дуюм ҳам кор мекунад. isAdult, параметр age. Return: age калон ё баробари ҳаждаҳ — ҷавоб true ё false.
Даъват: isAdult бисту, ҳаждаҳ, ҳафдаҳ. Иҷро. true, true, false. Ҳаждаҳсола ҳам мегузарад, ҳафдаҳсола не.

## 5:40 · Хатогиҳои маъмул (≈70 сония)
**Тасвир:** IDE бо хатоҳои сурх ва ишораҳои зард («💡»); дар кунҷ «Хатои 1 / 3» …

Се хатои маъмули функсия.
Якум: фаромӯш кардани даъват. Функсия навишта шуд, аммо даъват нашуд — ҳеҷ чиз намешавад.
Дуюм: return-ро нанавиштан. Агар дар double return нагузорем, ҷавоб undefined мешавад — «ҳеҷ чиз». Return лозим!
Саввум: вуруд надодан. Агар greet-ро бе ном даъват кунем, дар натиҷа «Салом, undefined!» мешавад. Параметр қимат интизор аст.

## 6:50 · Вазифаҳо ва санҷиш (≈65 сония)
**Тасвир:** саҳифаи «5 · Функсия» дар IDE, вазифаи 1, 2, 3, тугмаи «✅ Санҷиш»; сипас `double(double(3))`, «?» бо соат, «Пауза кунед».

Ва акнун вазифа барои шумо. Дар IDE ҷадвали «панҷ, Функсия»-ро кушоед. Се вазифа ҳаст.
Якум: функсияи double нависед, ки рақамро ду баробар кунад ва баргардонад. Дуюм: isAdult — агар age калон ё баробари ҳаждаҳ бошад, true. Саввум: greet — «Салом, ном!» баргардонад.
IDE месанҷад ва мегӯяд, ки дуруст аст ё не.
Ва санҷиши нав: ҳамон функсияи double. Консол лог, double, дар дохил боз double, се. Чӣ мешавад? Видеоро пауза кунед ва фикр кунед.
…
Ҷавоб: дувоздаҳ. Аввал дарун: double се — шаш. Баъд берун: double шаш — дувоздаҳ. Функсияро ба функсия додан мумкин аст!

## 7:55 · Хулоса ва даъват (≈35 сония)
**Тасвир:** хулоса: «Функсия = ном + вуруд + return»; `function double(x) { return x * 2; }`; корти «Дарси 6: Объект».

Хулоса мекунем. Функсия — рецепти барнома: як маротиба менависем, бисёр бор даъват мекунем. Вуруд — параметр, ҷавоб — return.
Шпаргалкаи бепул бо ҳамаи ин мисолҳо дар тавсиф аст.
Дарси оянда — объект: чӣ тавр маълумоти як чизро дар як ҷо нигоҳ медорем. Обуна шавед, то аз ҷаҳони барномасозӣ бехабар намонед.

## Код дар видео (санҷидашуда)
```js
function sayHello() {
  console.log("Салом!");
}
sayHello();   // «Салом!» (бе даъват — ҳеҷ чиз)
sayHello();
sayHello();

function greet(name) {
  console.log("Салом, " + name + "!");
}
greet("Нигина");   // Салом, Нигина!
greet("Фарҳод");   // Салом, Фарҳод!

function double(x) {
  return x * 2;
}
console.log(double(5));   // 10
let result = double(4);   // 8
console.log(result + 1);  // 9

function isAdult(age) {
  return age >= 18;
}
console.log(isAdult(20), isAdult(18), isAdult(17));   // true true false

// Хато 1: функсия навишта шуд, аммо даъват нашуд — ҳеҷ чиз намешавад
// Хато 2: function double(x) { x * 2; }  →  console.log(double(5)) → undefined
// Хато 3: greet() → «Салом, undefined!»

// Санҷиш: console.log(double(double(3)));   // 12
```
