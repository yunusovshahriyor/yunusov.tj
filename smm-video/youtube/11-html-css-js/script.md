## 0:30 · Образи хона ва браузер (≈75 сония)
**Тасвир:** хона: девор (HTML) → ранг ва тирезаҳо (CSS) → чароғ ва тугма (JavaScript). Сипас: браузер ← сервер: се файл `index.html`, `style.css`, `script.js` (аз дарси 10).

Тасаввур кунед, ки хона месозем. Аввал деворҳо: бе онҳо хона нест. Ин HTML аст — сохтори саҳифа: сарлавҳа, матн, тугма, сурат.
Баъд ранг: деворро кабуд мекунем, тирезаро калон. Ин CSS аст — намуд ва зебоӣ.
Ва барқ: чароғ, ки бо тугма равшан мешавад. Ин JavaScript аст — ҳаракат ва рафтор.
Дар дарси гузашта дидем, ки браузер саҳифаро аз сервер мегирад. Сервер се файл мефиристад: index.html — сохтор, style.css — намуд, script.js — рафтор. Браузер онҳоро якҷоя мехонад ва саҳифаро нишон медиҳад.
Ин се забон ҳамеша дар як ҷо кор мекунанд. Бе HTML саҳифа нест. Бе CSS саҳифа сафед ва оддӣ мешавад. Бе JavaScript саҳифа кор намекунад — ҳаракат надорад.
Дар хона ҳам ҳамин тавр: сохтмончӣ деворҳоро мебардорад, рассом ранг мекунад, барқчӣ чароғро мепайвандад. Се корманд — се касб — як хона. Дар барномасозӣ шумо ҳар серо ба тадриҷ меомӯзед, ва ҳоло ҳар се ҷудо-ҷудо ва баъд якҷоя.

## 1:47 · HTML: сохтор (≈176 сония)
**Тасвир:** майдони озмоиш: равзанаи HTML дар чап, пеш-намоиш дар рост. Код ҳарф ба ҳарф; теги кушода ва пӯшида бо ранг. Сипас рӯйхат, пайванд ва сурат.

Ба майдони озмоиш мегузарем. Пайванд дар тавсиф аст, ҳамроҳи ман нависед. Се равзана мебинед: HTML, CSS ва JavaScript. Дар рост — натиҷа, ки фавран нав мешавад.
HTML аз тегҳо иборат аст. Тег — калима дар қавсҳои кунҷӣ. Масалан, h1 — сарлавҳаи калон. Мекушоем: h1, ва менависем «Салом!». Баъд мепӯшем: қавси кунҷӣ, хатти моил ва h1. Дар паҳлӯ саҳифа фавран пайдо шуд!
Қоида: ҳар тег кушода ва пӯшида мешавад, матн дар байн. Мисли қуттӣ: сарпӯшро мекушоем, чизе мегузорем, сарпӯшро мепӯшем.
Сарлавҳа панҷ андоза дорад: h1 — калонтарин, баъд h2, h3 ва то h6. h1 мегузорем як маротиба — барои сарлавҳаи асосӣ. h2 — барои қисмҳои саҳифа.
Ҳоло p — сархат. «Ман барномасоз мешавам». Ва button — тугма: «Пахш кун». Се чиз дар саҳифа: сарлавҳа, матн ва тугма.
Рӯйхат: ul — рӯйхати нуқтадор, ва дар дохилаш li — ҳар хат. Се хат: HTML, CSS, JavaScript.
Пайванд: a — ва дар дохили тег як хусусияти махсус: href — суроға. Ба ҷои суроға менависем суроғаи мини-IDE. Матни пайванд: «Мини-IDE». Пахш мекунем — ба сайт меравем.
Сурат: img — ва хусусияти src, яъне суроғаи сурат, ва alt — матни ивазкунанда. Ин тегро пӯшидан лозим нест: он танҳо кушода мешавад.
Номи тегҳоро ба забони англисӣ мефаҳмем — ва дар хотир мондан осон мешавад. h — аз heading, яъне сарлавҳа. p — аз paragraph, яъне сархат. a — аз anchor, яъне лангар, ки ба ҷои дигар мебарад. ul — рӯйхати нуқтадор, li — як хати рӯйхат. Ва button — тугма.
Ва саҳифаи пурра чунин аст: html, дар дохилаш head — маълумоти саҳифа, масалан title, номи саҳифа дар ҷадвали браузер, ва body — он чизе, ки мебинем. Ҳамаи тегҳои пештара — дар дохили body.
Хулоса: HTML — тегҳо. Ҳар тег мегӯяд, ки ин чӣ аст: сарлавҳа, матн, тугма, рӯйхат, пайванд ё сурат.
Ва чӣ тавр ин файлро дар компютери худатон месозем? Хеле оддӣ. Дар Блокнот ё дар ҳар муҳаррири матн код менависем. Файлро бо номи index нуқта html нигоҳ медорем. Ду маротиба пахш мекунем — браузер файлро мекушояд ва саҳифаро нишон медиҳад. Ин ҳама чиз лозим аст: на барномаи махсус, на интернет.

## 4:45 · CSS: ранг, намуд ва «қуттӣ» (≈149 сония)
**Тасвир:** равзанаи CSS: `h1 { color: #BD93F9; }`; сарлавҳа бунафш мешавад. Сипас корти `.card`: қуттии картонӣ бо чор қабат — padding, border, margin.

Ҳоло ранг мекунем. Ба равзанаи CSS мегузарем. CSS се қисм дорад: интихобкунанда, хусусият ва қимат.
Интихобкунанда — барои кӣ: h1. Қавси фигурӣ. Хусусият — чӣ иваз мекунем: color, яъне ранг. Ду нуқта. Қимат — кадом ранг: бунафш. Нуқтавергул. Сарлавҳа бунафш шуд!
Ҳар хусусият — як сатр: ном, ду нуқта, қимат, нуқтавергул. Ба ҷои калима ранг метавонем бо рамз нависем — дар поён мебинем.
Дигар хусусиятҳо: background — замина, font-size — андозаи ҳарф. Барои тугма: background — бунафш, color — торик, border-radius — гирдкунии кунҷҳо, padding — фосила дар дохил. Тугма зебо шуд.
Ранг навиштан се роҳ дорад. Бо ном: red, green — оддитарин. Бо рамз: нишони панҷара ва шаш ҳарф ё рақам. Ва бо rgb — се рақам: сурх, сабз, кабуд. Ҳамааш яке аст — роҳи худро интихоб кунед.
Андоза бо пиксел навишта мешавад: бист пиксел, шонздаҳ пиксел. Ва ба тугма ҳолати «мушро овардан» илова мекунем: button, ду нуқта, hover — ва ранги нав, гулобӣ. Муш болои тугма — ранг иваз шуд. Ин ҳолат ҳангоми муш овардан кор мекунад.
Ва ҳоло ҷузъи муҳим — класс. Агар бисёр чиз дошта бошем, ба ҳар кадом як ном медиҳем. Дар HTML менависем: div бо хусусияти class баробари card. Дар CSS: нуқта ва card. Нуқта маънои «класс»-ро дорад.
Ҳар элемент дар CSS қуттӣ аст — ҳамон қуттии картонӣ аз дарси якум! Он чор қабат дорад. Дохил — матн. Баъд padding — фосила байни матн ва девори қуттӣ. Баъд border — худи девор. Ва margin — масофа аз қуттиҳои дигар.
Менависем: padding бист пиксел, margin бист пиксел, border ду пиксел бунафш, border-radius шонздаҳ. Корт пайдо шуд. Ҳамаи ин қиматҳоро худатон иваз кунед ва бубинед, ки чӣ мешавад.
Хулоса: CSS — интихобкунанда, хусусият, қимат. Класс ба элемент ном медиҳад. Ва ҳар элемент — қуттӣ бо чор қабат.

## 7:16 · JavaScript: ҳаракат (≈213 сония)
**Тасвир:** равзанаи JS: `function greet() { … }`; тугма пахш мешавад → сарлавҳа «Салом, Нигина!» мешавад. Нишона: «дарси 5». Сипас: input + «Салом» ва тугмаи «Торик».

Пеш аз он ки код нависем, як чизи муҳимро фаҳмем: браузер саҳифаро чӣ тавр мебинад. Вай HTML-ро ба дарахт табдил медиҳад. Реша — html. Аз он ду шоха: head ва body. Аз body шохаҳо: h1, p, тугма. Ҳар шоха — як элемент. Ин дарахт DOM ном дорад.
JavaScript аз ин дарахт элементро меёбад ва иваз мекунад. Мисли ин ки шумо дар хона чароғро меёбед ва тугмаашро пахш мекунед. Барои ёфтан — document. Ин «ҳамаи саҳифа» аст.
Ва акнун барқ. Ба равзанаи JavaScript мегузарем. Бо функсия аз дарси панҷум: function greet.
Дар дохил: document нуқта querySelector, дар қавс «h1». Ин «саҳифа, сарлавҳаро ёб» аст. Баъд нуқта textContent баробари «Салом, Нигина!» — матнро иваз мекунем.
Ва ба тугма мепайвандем: дар HTML тугма onclick баробари greet. Яъне «вақте пахш кунанд — greet-ро иҷро кун». Пахш мекунем — сарлавҳа иваз шуд! Дидед? Функсия аз дарси панҷум — акнун саҳифаро иваз мекунад.
Ҳоло бо вуруд. Дар HTML майдони input менависем — барои ном. Тугма «Салом», ва p бо номи out — барои ҷавоб.
Функсияи hello. let name баробари document нуқта getElementById, «name», нуқта value — ин қимати навиштаи корбар. Ин ҳамон тағйирёбанда аз дарси якум! Баъд: ҷавоб баробари «Салом, » плюс name плюс «!». Матнҳоро бо плюс ҷамъ мекунем — аз дарси якум.
Ном менависем: «Фарҳод». Пахш мекунем: «Салом, Фарҳод!». Саҳифа ҷавоб медиҳад!
Ва тугмаи «Торик». Дар CSS: body нуқта dark — замина торик, матн сафед. Дар JavaScript: функсияи toggle: document нуқта body нуқта classList нуқта toggle, «dark». Пахш мекунем — саҳифа торик. Боз пахш — равшан. Мисли чароғи хона: як тугма, ду ҳолат.
Хулоса: JavaScript элементро меёбад ва иваз мекунад. Ва ба пахши тугма вокуниш нишон медиҳад.
Ва як мисоли дигар — рақамгир. Дар HTML: h2 бо номи num, дар дохилаш сифр, ва тугма «плюс як». Дар JavaScript: let count баробари сифр — ҳамон қуттӣ аз дарси якум. Баъд функсияи add: count баробари count плюс як. Ва саҳифаро нав мекунем: document нуқта getElementById, «num», нуқта textContent баробари count.
Пахш мекунем: як. Пахш мекунем: ду. Се! Рақам ҳар бор калон мешавад. Қуттии count қимати худро нигоҳ медорад, ва саҳифа онро нишон медиҳад.
Дар ин ҷо се дарс якҷоя кор мекунанд: тағйирёбанда аз дарси як, функсия аз дарси панҷ, ва ҳамаи инҳо дар саҳифа. Дар сайтҳои воқеӣ — ҳисобкунаки лайкҳо, сабади харид — ҳамин тавр кор мекунад.
Ва барои санҷиш, console нуқта log дар саҳифа ҳам кор мекунад. Натиҷаро дар браузер бо клавиши F12 мебинем — дар равзанаи Console. Ин ҳамон console нуқта log аз дарсҳои пештара аст, танҳо ҳоло дар сайт.

## 10:51 · Лоиҳа: корти профил (≈111 сония)
**Тасвир:** майдони озмоиш: корт — ном, матн, рӯйхати малакаҳо, input + «Салом», «Торик». Рангҳо ва қуттӣ дар як ҷо.

Ва ана — корт кор мекунад: сохтор аз HTML, намуд аз CSS, ҳаракат аз JavaScript. Ин аввалин саҳифаи шумост!

## Код дар видео (санҷидашуда дар Chromium)
```html
<!DOCTYPE html>
<html>
<head><meta charset="utf-8"><title>Саҳифаи ман</title></head>
<body>
  <div class="card">
    <h1 id="title">Нигина</h1>
    <p>Ман барномасоз мешавам.</p>
    <ul><li>HTML</li><li>CSS</li><li>JavaScript</li></ul>
    <a href="https://yunusovshahriyor.github.io/yunusov.tj/">Мини-IDE</a>
    <img src="photo.jpg" alt="Сурат">
    <input id="name" placeholder="Номи шумо"><button onclick="hello()">Салом</button>
    <p id="out"></p>
    <button onclick="greet()">Пахш кун</button>
    <button onclick="toggle()">Торик</button>
  </div>
</body>
</html>
```
```css
h1 { color: #BD93F9; }
.card { background: #252526; color: #fff; padding: 20px; margin: 20px; border: 2px solid #BD93F9; border-radius: 16px; }
button { background: #BD93F9; color: #1E1E1E; padding: 10px 20px; border-radius: 8px; border: 0; }
body.dark { background: #1E1E1E; color: #fff; }
```
```js
function greet() {
  document.querySelector("h1").textContent = "Салом, Нигина!";
}
function hello() {
  let name = document.getElementById("name").value;
  document.getElementById("out").textContent = "Салом, " + name + "!";
}
function toggle() {
  document.body.classList.toggle("dark");
}
```
```
// Натиҷа: рӯйхат → HTML, CSS, JavaScript; .card → padding 20px, margin 20px, border 2px, border-radius 16px;
//         «Фарҳод» + «Салом» → «Салом, Фарҳод!»; «Торик» → замина rgb(30, 30, 30).
```
