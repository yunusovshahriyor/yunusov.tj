## 0:00 · Хук (≈22 сония)
**Тасвир:** сайти оддӣ (сарлавҳа, матн, тугма) → се қабат ҷудо мешавад: сохтор, ранг, ҳаракат. Дар кунҷ: «Дарси 11 · HTML, CSS, JS».

Салом, дӯстон! Ҳар сайт, ки шумо мекушоед, аз се забон сохта шудааст. Яке сохтор медиҳад, дигаре ранг, саввумӣ — ҳаракат.
Дар ин видео ҳар се забонро мебинем ва худамон як саҳифаи хурд месозем. Дар охир санҷиши нав ҳаст. Оғоз мекунем!

## 0:24 · Образи хона (≈50 сония)
**Тасвир:** хона: девор (HTML) → ранг ва тирезаҳо (CSS) → чароғ ва тугма (JavaScript). Рӯйхат: «HTML = девор», «CSS = ранг», «JS = барқ».

Тасаввур кунед, ки хона месозем. Аввал деворҳо: бе онҳо хона нест. Ин HTML аст — сохтори саҳифа: сарлавҳа, матн, тугма, сурат.
Баъд ранг: деворро кабуд мекунем, тирезаро калон. Ин CSS аст — намуд ва зебоӣ.
Ва барқ: чароғ, ки бо тугма равшан мешавад. Ин JavaScript аст — ҳаракат ва рафтор.
Се забон — се кори гуногун. Ва ҳар се дар як саҳифа якҷоя кор мекунанд.

## 1:14 · HTML: сохтор (≈70 сония)
**Тасвир:** майдони озмоиш: равзанаи HTML дар чап, пеш-намоиш дар рост. Код ҳарф ба ҳарф; теги кушода ва пӯшида бо ранг.

Ба майдони озмоиш мегузарем. Пайванд дар тавсиф аст, ҳамроҳи ман нависед.
HTML аз тегҳо иборат аст. Таг — калима дар қавсҳои кунҷӣ. Масалан, h1, сарлавҳаи калон. Мекушоем: h1, сарлавҳа «Салом!» ва мепӯшем: бо ҳамон ном ва хатти моил.
Дар паҳлӯ саҳифа фавран пайдо мешавад! Ва p — сархат: «Ман барномасоз мешавам». Ва button — тугма: «Пахш кун».
Қоида: ҳар таг мекушояд ва мепӯшад. Матн дар байн.

## 2:24 · CSS: ранг ва намуд (≈65 сония)
**Тасвир:** равзанаи CSS: `h1 { color: #BD93F9; }`; сарлавҳа бунафш мешавад; тугма: `background`, `padding`, `border-radius`.

Ҳоло ранг мекунем. Ба равзанаи CSS мегузарем. CSS се қисм дорад: интихобкунанда, хусусият ва қимат.
h1, қавси фигурӣ: color, ду нуқта, бунафш, нуқтавергул. Сарлавҳа бунафш шуд!
Ва тугма: background — замина, padding — фосила дар дохил, border-radius — гирдкунии кунҷҳо. Тугма зебо шуд.
Ҳар хусусият — як сатр: ном, ду нуқта, қимат ва нуқтавергул.

## 3:29 · JavaScript: ҳаракат (≈75 сония)
**Тасвир:** равзанаи JS: `function greet() { … }`; тугма пахш мешавад → сарлавҳа «Салом, Нигина!» мешавад. Нишона: «дарси 5».

Ва акнун барқ. Ба равзанаи JavaScript мегузарем. Бо функсия аз дарси панҷум: function greet. Дар дохил: document нуқта querySelector, дар қавс «h1» — ин «саҳифа, ёфтани сарлавҳа» аст. Нуқта textContent баробари «Салом, Нигина!» — матнро иваз мекунем.
Ва ба тугма мепайвандем: дар HTML тугма onclick баробари greet. Пахш мекунем — сарлавҳа иваз шуд!
Дидед? HTML — тугма ва сарлавҳа, CSS — рангашон, JavaScript — рафтор.

## 4:44 · Ҳар се якҷоя (≈55 сония)
**Тасвир:** тугмаи нав «Торик»; пахш мекунем — саҳифа торик мешавад (замина #1E1E1E). Се равзана бо ҳам.

Ҳоло ҳар се якҷоя. Мехоҳем, ки тугма саҳифаро торик кунад.
CSS: body нуқта dark — замина торик, матн сафед. JavaScript: функсияи toggle — document нуқта body нуқта classList нуқта toggle, «dark». HTML: тугмаи нав «Торик» бо onclick баробари toggle.
Пахш мекунем — саҳифа торик. Боз пахш — равшан. Ин мисли чароғи хона: як тугма, ду ҳолат.
Ҳамин тавр сайтҳои воқеӣ кор мекунанд: сохтор, намуд ва рафтор.

## 5:39 · Хатогиҳои маъмул (≈60 сония)
**Тасвир:** майдони озмоиш бо хатои сурх ва ишораи зард («💡»); дар кунҷ «Хатои 1 / 3» …

Се хатои маъмул.
Якум: тагро напӯшидан. Агар h1-ро кушоем ва напӯшем, матни пас аз он низ ба сарлавҳа дохил мешавад ва калон менамояд. Ҳамеша мепӯшем.
Дуюм: дар CSS ду нуқта ё нуқтавергулро фаромӯш кардан. color бунафш бе ду нуқта — ранг кор намекунад. Ном, ду нуқта, қимат, нуқтавергул.
Саввум: дар JavaScript номи нодуруст. Агар querySelector бо «h2» бинависем, аммо дар саҳифа h2 нест — хатои «Cannot set properties of null». Яъне элемент ёфт нашуд.

## 6:39 · Вазифаҳо ва санҷиш (≈65 сония)
**Тасвир:** саҳифаи «11 · HTML, CSS, JS» дар майдони озмоиш, вазифаи 1, 2, 3, «✅ Санҷиш»; сипас се корт: сарлавҳа / ранги сабз / пахши тугма — «HTML, CSS ё JS?», «Пауза кунед».

Ва акнун вазифа барои шумо. Дар майдони озмоиш ҷадвали «ёздаҳ»-ро кушоед. Се вазифа ҳаст.
Якум: HTML — сарлавҳаи h1 бо номи худатон. Дуюм: CSS — ранги сарлавҳаро сурх кунед. Саввум: JavaScript — бо пахши тугма матнро иваз кунед.
Ва санҷиши нав. Се чиз: якум — сарлавҳа сохтан. Дуюм — ранги сабз додан. Саввум — пахши тугма, ки матнро иваз мекунад. Кадоме HTML аст, кадоме CSS, кадоме JavaScript? Видеоро пауза кунед ва фикр кунед.
…
Ҷавоб: сарлавҳа — HTML, ранги сабз — CSS, пахши тугма — JavaScript. Сохтор, намуд, рафтор!

## Код дар видео (санҷидашуда дар Chromium)
```html
<h1>Салом!</h1>
<p>Ман барномасоз мешавам.</p>
<button onclick="greet()">Пахш кун</button>
<button onclick="toggle()">Торик</button>
```
```css
h1 { color: #BD93F9; }
button { background: #BD93F9; color: #1E1E1E; padding: 10px 20px; border-radius: 8px; border: 0; }
body.dark { background: #1E1E1E; color: #fff; }
```
```js
function greet() {
  document.querySelector("h1").textContent = "Салом, Нигина!";
}
function toggle() {
  document.body.classList.toggle("dark");
}
```
```
// Натиҷа: h1 → «Салом!», пас аз пахш → «Салом, Нигина!»; рангаш rgb(189, 147, 249);
//         тугмаи «Торик»: замина сафед ↔ #1E1E1E.
// Хато 1: <h1>Салом!<p>Матн</p>  → <p> ба дохили <h1> меафтад
// Хато 2: h1 { color #BD93F9 }   → ду нуқта нест, ранг кор намекунад
// Хато 3: document.querySelector("h2").textContent = "x"
//         → TypeError: Cannot set properties of null (setting 'textContent')
```
