## 1:17 · Аввалин давр дар IDE (≈110 сония)
**Тасвир:** IDE, код ҳарф ба ҳарф; се қисми `for (...)` бо се нишона: оғоз / шарт / қадам; қуттии `i` 1 → 2 → 3; тугмаи «▶ Иҷро»; натиҷа дар поён.

Ба IDE мегузарем. Пайванд дар тавсиф аст, ҳамроҳи ман нависед.
Менависем: for, дар қавс се қисм. Якум: let i баробари як — оғоз. Ин i ҳамон қуттии дарси якум аст! Танҳо ҳоло қиматаш ҳар бор иваз мешавад.
Дуюм: i калон ё баробар не, балки хурд ё баробари панҷ — шарт. Ин ҳамон шарт аз дарси дуюм аст: то он дуруст аст, давр давом мекунад.
Саввум: i плюс плюс — қадам: ҳар бор як илова кун.
Дар дохили қавсҳои фигурӣ: консол лог, «Нишаст-хез» плюс i.
Иҷро мекунем. Нишаст-хез як, ду, се, чор, панҷ. Панҷ бор!
Ҳоло панҷро ба ҳазор иваз мекунем. Иҷро. Ҳазор сатр — камтар аз як сония. Ана қуввати давр!

## 3:07 · Давр қадам ба қадам (≈75 сония)
**Тасвир:** ҷадвали давр: i = 1 → «1 <= 3? ҳа» → экран → i++; i = 2 …; i = 4 → «4 <= 3? не» → бас. Сипас IDE: `i += 2` ва `i--`.

Бубинем, дар дохили давр чӣ мешавад. Мисоли хурд: аз як то се.
i мешавад як. Шартро месанҷем: як хурд ё баробари се? Ҳа — кор иҷро мешавад. Баъд қадам: i мешавад ду. Боз шарт: ҳа, иҷро. Баъд i мешавад се. Боз ҳа. Баъд i мешавад чор. Чор аз се калон аст — шарт «не»! Давр тамом мешавад.
Хулоса: шарт, кор, қадам. Шарт, кор, қадам. То шарт «не» мешавад.
Қадам ҳамеша як нест. i плюс баробари ду — ҳар бор ду: дуву чор, шаш, ҳашт, даҳ. Ва i минус минус — як кам мекунад, барои ҳисоби баръакс: аз даҳ то як.

## 4:22 · Ҷамъ аз 1 то 100 (≈55 сония)

Қуттии sum месозем, дар он сифр мегузорем. Баъд давр аз як то сад. Дар дохил: sum баробари sum плюс i — яъне ба сумма i-ро илова мекунем.
Ба охир, консол лог, sum. Иҷро. Панҷ ҳазору панҷоҳ! Дастӣ ҳисоб кардан чанд дақиқа мегирифт, компютер — як лаҳза.

## Код дар видео (санҷидашуда)
```js
for (let i = 1; i <= 5; i++) {
  console.log("Нишаст-хез " + i);
}
// 1…5; бо 1000 — ҳазор сатр

for (let i = 2; i <= 10; i += 2) {
  console.log(i);
}
// 2, 4, 6, 8, 10

for (let i = 10; i >= 1; i--) {
  console.log(i);
}
// 10, 9, … 1

let sum = 0;
for (let i = 1; i <= 100; i++) {
  sum = sum + i;
}
console.log(sum);
// 5050

// Хато 1: for (let i = 1; i < 5; i++) → 1, 2, 3, 4 (панҷ нест)
// Хато 2: for (let i = 1; i <= 5; ) { … } — даври бепоён (IDE баъд аз 2,5 с қатъ мекунад)
// Хато 3: for (let i = 1; i <= 3; i++) {}  console.log(i); → ReferenceError: i is not defined

// Санҷиш: for (let i = 0; i < 3; i++) { console.log("Салом"); } → 3 бор (i = 0, 1, 2)
```
