## Сохтор: 5 марҳила (хати пешрафт дар боло)

## Матн (барои субтитрҳо; **калимаи асосӣ** — бо ранги аксент)

**Сайтҳо пароли шуморо чӣ тавр нигоҳ медоранд?**

`1/5 ПАРОЛ`
Шумо дар сайт сабти ном мекунед ва пароли **1234**-ро менависед. Сайти боэътимод худи паролро **ҳеҷ ҷо** нигоҳ намедорад. Ҳатто барномасози худи сайт онро намедонад.

`2/5 ХЕШ`
Ба ҷои пароль сайт **хеши** онро нигоҳ медорад. Хеш — мисли **гӯштқимакунак** ҳаст: гӯштро қийма кардан осон, вале қиймаро ба гӯшт баргардонда намешавад.
`sha256("1234")` — ва аз пароль ин матни дароз мемонад. Як рақам илова кунед — `12345` — ва хеш **тамоман дигар** мешавад.

`3/5 ВОРИДШАВӢ`
Вақте шумо ворид мешавед, сайт пароли навиштаатонро боз «қийма» мекунад ва бо хеши дар база будагӣ **муқоиса** мекунад. Якхела — марҳамат, дароед!

`4/5 ХАКЕР`
Аммо як мушкил ҳаст: пароли якхела ҳамеша **хеши якхела** медиҳад. Хакер хеши паролҳои маъмулро пешакӣ ҳисоб мекунад — 1234, qwerty, password — ва дар базаи дуздидашуда ҷустуҷӯ мекунад.

`5/5 SALT`
Барои ҳамин ба ҳар пароль **Salt** илова мекунанд. Salt — ин матни тасодуфӣ мебошад, ки барои ҳар як пароль алоҳида гузошта мешавад. Пароль якхела, Salt гуногун — **хеш гуногун**. Ва алгоритмҳои махсус — **bcrypt** ва **Argon2** — кори хакерҳоро солҳо дароз мекунанд.

## Код дар видео (натиҷаҳо дар Node.js санҷида шудаанд)
```js
const crypto = require("crypto");
const sha256 = (s) => crypto.createHash("sha256").update(s).digest("hex");

sha256("1234");      // 03ac674216f3e15c761ee1a5e255f067953623c8b388b4459e13f978d7c846f4
sha256("12345");     // 5994471abb01112afcc18159f6cc74b4f511b99806da59b3caf5a9c173cacfc5

// salt + пароль
sha256("8f3a" + "1234");  // 03b60f85c71cc99684037a2c9d45ac3c08ac28f5db666809e7121f4514e06812
sha256("c7d1" + "1234");  // 9e3f1b6bc40b29895971788ea2f4db8bbb6793e443273a912014584024377192
```
Дар экран хешҳо кӯтоҳ: `03ac6742…`, `59944 71a…`, `03b60f85…`, `9e3f1b6b…`.

## Нақшаи тасвир (стили тира: `#1E1E1E`, тӯри хира, хатҳои тунук, аксент бунафш → гулобӣ, хеш — бирюзаӣ `#4EC9B0`)
| Марҳила | Тасвир |
|---|---|
| Хук | Формаи «Даромад» (логин `shahriyor`, пароль `••••`), тамғаи `1234` болои он; «?» калон |
| 1/5 ПАРОЛ | Корти `DATABASE` (username / password): дар сутуни пароль ҷойи холӣ ва мӯҳри **«НЕСТ»** |
| 2/5 ХЕШ | Тамғаи `1234` ба гӯштқимакунаки хаттӣ меафтад → аз он тасмаи `03ac6742…` мебарояд; тирча ба қафо бо «✕». Баъд терминал: `sha256("1234")` чоп мешавад, баъд `12345` → хеши дигар; ду хешро паҳлӯи ҳам: «ҳеҷ умумият нест» |
| 3/5 ВОРИДШАВӢ | Ноутбук: пароль → гӯштқимакунак → хеш → муқоиса бо база: `03ac6742… = 03ac6742…` ✓ → «Хуш омадед!» |
| 4/5 ХАКЕР | Базаи 4 корбар: ду корбар хеши якхела (рангаи сурх). Нишонаи хакер + «ҷадвали тайёр»: `1234 → 03ac6742…`, `qwerty → 65e84be3…` — мувофиқат ёфт! |
| 5/5 SALT | Намакдон бо тамғаи `salt` матни тасодуфӣ мепошад: `8f3a` + `1234`, `c7d1` + `1234` → хешҳои гуногун; сутуни нав `salt` дар база. Баъд тамғаҳо `bcrypt`, `Argon2` + соати рег ⏳ |
| Хулоса | Корти база: `username · salt · hash` — бе сутуни пароль; сатр: «паролро намедонад — танҳо хеши онро бо Salt» |
| Охир | Савол «Як пароль дар чанд сайт? Ҳа / Не» + огоҳӣ «паролро нанависед» → баннери шарҳ «ПАРОЛ» бо муқоваи PDF (`pdf/parol/7-qoidai-paroli-bekhatar.pdf`) ва ишораи «→ Direct»; корти обуна |
