# Reels (иловагӣ, анимация) — «Даври бепоён» (~40–45 сония) — нусхаи 1 (интизори тасдиқ)

Формат нав: **анимацияи ҳаҷвӣ бо қаҳрамон** (stickman «Одамак» бо ноутбук). Ҳадаф — шавқовар, ҳаҷвӣ ва омӯзанда. Идея аз видеои истинодӣ (қаҳрамони зард бо ноутбук, код ба ҷаҳон таъсир мекунад) илҳом гирифта шуд, вале **ҳикоя, қаҳрамон, код (JavaScript), дизайн ва садо аслӣ ҳастанд**.
Мавзӯъ: дарси 3 (Давр) — «чаро давр метавонад бепоён шавад ва чӣ тавр онро қатъ кунем».
Фикри ягона: **давр бе шарти хуруҷ ҳеҷ гоҳ намеистад. Давр = оғоз + шарт + қадам.**

## Қаҳрамон ва услуб (аслӣ)
- **Одамак** — stickman бо хатҳои сафед ва рӯшноии бунафш (`#BD93F9`), сараш давра бо градиенти бунафш → гулобӣ; ноутбуки ӯ экрани VS Code дорад. Сояи неон, замина `#1E1E1E` бо нуқтаҳои хира (шабака).
- «Салом» ҳамчун **кӯчакчаҳои бунафш/гулобӣ (pill)** аз ноутбук мепараранд ва ҷамъ мешаванд.
- Ноутбук **гарм мешавад**: ранги экран бунафш → норанҷӣ → сурх (`#F48771`), мӯйсафед (шумораи гармӣ), фан чарх мезанад.
- Субтитр калима ба калима (мисли роликҳои пештара), садоҳо: клавиатура, поп, riser, фан, парвоз, ding.
- Шапка нест. Матн дар 1080×1350-и марказ.

## Код дар видео (санҷидашуда дар Node.js; давраи бепоён дар видео намоиш дода мешавад, на воқеан иҷро)
```js
// ❌ ҳеҷ гоҳ намеистад — шарт ҳамеша true
while (true) { console.log("Салом"); }

// ✅ се қисм: оғоз; шарт; қадам
for (let i = 0; i < 3; i++) { console.log("Салом"); }   // Салом ×3

// санҷиш: қадам нест → i ҳеҷ гоҳ зиёд намешавад → бепоён
for (let i = 0; i < 3; ) { console.log("Салом"); }
```

## Санҷиш
Ҷавоби дуруст: **бепоён**. i ҳамеша 0 мемонад, шарт `0 < 3` ҳамеша дуруст аст. Ҷавобро дар ролик нагӯем.
