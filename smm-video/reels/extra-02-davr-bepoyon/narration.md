# Reels (иловагӣ, анимация) — «Даври бепоён» (47,5 с, БЕ ОВОЗ ВА БЕ ШАРҲ)

Формат нав: **анимацияи ҳаҷвӣ бо қаҳрамон** (stickman «Одамак» бо ноутбук). Ҳадаф — шавқовар, ҳаҷвӣ ва омӯзанда. Идея аз видеои истинодӣ (қаҳрамони зард бо ноутбук, код ба ҷаҳон таъсир мекунад) илҳом гирифта шуд, вале **ҳикоя, қаҳрамон, код (JavaScript), дизайн ва садо аслӣ ҳастанд**.
Мавзӯъ: дарси 3 (Давр) — «чаро давр метавонад бепоён шавад ва чӣ тавр онро қатъ кунем».
Фикри ягона: **давр бе шарти хуруҷ ҳеҷ гоҳ намеистад. Давр = оғоз + шарт + қадам.**

## Қаҳрамон ва услуб (аслӣ)
- **Одамак** — stickman бо хатҳои сафед ва рӯшноии бунафш (`#BD93F9`), сараш давра бо градиенти бунафш → гулобӣ; ноутбуки ӯ экрани VS Code дорад. Сояи неон, замина `#1E1E1E` бо нуқтаҳои хира (шабака).
- «Салом» ҳамчун **кӯчакчаҳои бунафш/гулобӣ (pill)** аз ноутбук мепараранд ва ҷамъ мешаванд.
- Ноутбук **гарм мешавад**: ранги экран бунафш → норанҷӣ → сурх (`#F48771`), мӯйсафед (шумораи гармӣ), фан чарх мезанад.
- Субтитр калима ба калима (мисли роликҳои пештара), садоҳо: клавиатура, поп, riser, фан, парвоз, ding.
- Шапка нест. Матн дар 1080×1350-и марказ.

## Нусхаи ниҳоӣ v2: БЕ ОВОЗ ВА БЕ ШАРҲ (қарори муаллиф)
Мисли видеои истинодӣ: **ҳеҷ субтитр ва шарҳ нест**. Тамошобин мақсадро аз ҳаракати Одамак ва коди дар ҳаво менавиштагӣ мефаҳмад. Матн танҳо: код, «Салом»-ҳо, рақамҳо ва калимаи «ДАВР» дар охир.
Дарозӣ: **47,5 сония**. Садоҳо: қадамҳо, клавиатура (ҳар ҳарф), pop («Салом»-ҳо), riser/фан/buzz (гармшавӣ), hit/whoosh (парвози ноутбук), thud, ding/chime.

| Вақт | Чӣ рӯй медиҳад |
|---|---|
| 0–3 | Одамак бо ноутбук меояд (қадамзанӣ), менишинад. |
| 3–8 | Дар болояш фикр: се «Салом». Дар ҳаво код менависад: `while (true) { console.log("Салом"); }` бо курсори чашмакзананда. |
| 8–16 | Enter (▶). «Салом»-ҳо аз ноутбук мепаранд, шумораашон меафзояд. Ноутбук гарм мешавад (бунафш → норанҷӣ → сурх 🔥), Одамак арақ мерезад, ҳайрон, зери «Салом»-ҳо мемонад; ноутбук мепарад. |
| 19–23 | Ноутбук бармегардад. Одамак фикр мекунад 💡. `true` ишора мешавад, ♾️ чарх мезанад, ✅✅✅✅✅ — шарт ҳамеша дуруст. |
| 23–30 | Код интихоб ва нест мешавад. Коди нав менависад: `for (let i = 0; i < 3; i++)`. Се қисм бо се ранг ва рақами 1, 2, 3: `i = 0`, `i < 3`, `i++`. |
| 30.6–35 | Run. Қуттии `i`: 0 → 1 → 2 → 3. Се «Салом» дар паҳлӯ. `3 < 3` ва ✖ — давр қатъ мешавад. Одамак шод, ✨. |
| 38–43 | Санҷиш: `for (let i = 0; i < 3; ?)`. Кортҳо: 3 · 0 · ♾️. Одамак бо «?». |
| 43–47.5 | Шарҳ «ДАВР» → корти видеои YouTube → 🔔. Одамак даст меҷунбонад. |

## Матни зери пост (caption.txt, пешниҳод)
Одамак аз компютер се бор «Салом» хост — ва компютер ист накард 😅 Дар 40 сония мефаҳмед: давр чӣ тавр кор мекунад ва чаро шарт ва қадам муҳиманд. Санҷиш: агар for-давр i++ надошта бошад, чӣ мешавад? 🤔 3 бор, ҳеҷ чиз ё бепоён? Ҷавобро дар шарҳ нависед.

Калимаи «ДАВР»-ро ҳам нависед — видеои пурраи дарсро аз YouTube ба Direct мефиристам ▶️

## Нашр
