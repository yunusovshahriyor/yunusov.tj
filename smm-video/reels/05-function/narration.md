# Reels 5 — «Функсия» (~65–70 сония) — нусхаи 1 (интизори тасдиқ)

Қоида (ҳамон, ки дар «Рӯйхат»): хук бо натиҷа, «Дарси 5 / 12», пайвастагӣ бо дарсҳои 1–4 (қуттии `age`), калимаи рамз. Як ролик — як фикр: **функсия = тугмаи мошин: як бор месозӣ, борҳо пахш мекунӣ.**

## Матн (барои субтитрҳо)

**Як кодро даҳ бор навиштан лозим нест — як бор нависед, даҳ бор истифода баред. Чӣ тавр?**

Функсия!

Тасаввур кунед, ки мошини либосшӯӣ доред. Либосро мегузоред, тугмаро пахш мекунед — мошин худаш мешӯяд. Дарунаш чӣ мешавад, донистан лозим нест. Ҳар дафъа ҳамон тугма.

Дар барномасозӣ ҳам ҳамин тавр. Функсия — ин «мошини» барнома: якчанд сатри код, ки ба он ном додаем.

function greet(name) — ин ҳамон мошин. Дар дохили он: console.log("Салом, " + name). Ин мошинро сохтем, вале ҳанӯз коре накардааст.

Ҳоло онро даъват мекунем: greet("Алӣ") — Салом, Алӣ! greet("Мариям") — Салом, Мариям! Мошин як, натиҷа гуногун.

Дар қавс — name — ин ҳамон либос аст, ки ба мошин медиҳем.

Баъзан функсия натиҷа бармегардонад. Ин калимаи return аст. Ёдатон ҳаст қуттии age, ки 25 буд? function birthday(age) — return age + 1.

let age = 25. Ҳоло age = birthday(age) — ва дар қуттӣ 26.

Функсия дар ҳама ҷо ҳаст: тугмаи «лайк», ворид шудан ба ҳисоб, ҳисоби нарх дар мағоза.

Функсия = код бо ном: як бор менависӣ, борҳо истифода мебарӣ.

**Ва акнун санҷиш: ҳамон birthday. Агар birthday(birthday(25)) нависем, чанд мешавад? Ёдовар: аввал дохилии он иҷро мешавад. Ҷавобро дар шарҳ нависед.**

## Код дар видео (санҷидашуда дар Node.js)
```js
function greet(name) {
  console.log("Салом, " + name + "!");
}
greet("Алӣ");      // Салом, Алӣ!
greet("Мариям");   // Салом, Мариям!

function birthday(age) {
  return age + 1;
}
let age = 25;
age = birthday(age);
console.log(age);  // 26
```

## Санҷиш (дар экран)
```js
birthday(birthday(25))   // ?
```
Ҷавоби дуруст: **27** (дохилӣ → 26, берунӣ → 27). Ҷавобро дар ролик нагӯем.

## Нақшаи тасвир
| Қисм | Тасвир |
|---|---|
| Хук | Як блоки код 10 бор такрор мешавад → як функсияи ягона бо тугмаи «даъват»; «Чӣ тавр?» |
| Мошини либосшӯӣ | Либос меравад, тугма пахш мешавад, мошин мегардад, либоси тоза мебарояд |
| Функсия | Мошин ба блоки `function greet(name)` табдил меёбад (IDE) |
| Даъват | `greet("Алӣ")`, `greet("Мариям")` — терминал ду натиҷаи гуногун чоп мекунад |
| Параметр | `name` бо тир ба «либос» ишора мешавад |
| return | Қуттии `age` (25) ба `birthday` медарояд, бо `+1` бо «поп» берун меояд 26 |
| Дар ҳаёт | Тугмаи лайк, воридшавӣ, ҳисоби нарх |
| Хулоса | «ФУНКСИЯ = код бо ном» |
| Санҷиш | `birthday(birthday(25))` = `?`, соат |
| Охир | Шарҳ «ФУНКСИЯ» → баннери «Видеои пурра дар YouTube» → корти «Дарси 6: Объект» |
