## Код дар видео (санҷидашуда дар Node.js)
```js
let person = { name: "Алӣ", age: 25, city: "Душанбе" };
console.log(person.name);   // Алӣ
console.log(person.age);    // 25
person.age = 26;
person.job = "барномасоз";
console.log(person.age);    // 26
```

## Нақшаи тасвир
| Қисм | Тасвир |
|---|---|
| Хук | 10 тағйирёбанда (`name1`, `age1`, `city1`…) ба як корти `{ }` ҷамъ мешаванд; «Чӣ тавр?» |
| Шиноснома | Корт: акс-нишона, «ном / синну сол / шаҳр» |
| Объект | Корт ба блоки `{ name, age, city }` табдил меёбад (IDE) |
| Рӯйхат vs объект | Рӯйхат: `[0] [1] [2]`; объект: `name` `age` `city` — бо тир аз дарси 4 |
| Нуқта | `person.name` → «Алӣ», `person.age` → 25 (терминал) |
| Иваз | Қуттии `age` (25 → 26) дар дохили корт, «поп» |
| Илова | `job` ҳамчун сатри нав бо баргардонии лампа |
| Дар ҳаёт | Профили Instagram, мошин, мағоза — се корт |
| Хулоса | «ОБЪЕКТ = ном + қимат» |
| Санҷиш | Код + «?», соат |
| Охир | Шарҳ «ОБЪЕКТ» → баннери «Видеои пурра дар YouTube» → корти «Дарси 7: Хатогӣ» |
