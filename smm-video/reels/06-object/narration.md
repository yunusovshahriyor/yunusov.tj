**Барои маълумоҳои як одамро сапт кардан даҳ тағйирёбанда лозим нест — як объект кифоя аст. Чӣ тавр?**

Объект!

Тасаввур кунед, ки шиноснома дораед ва дар он ҷойгир аст: ном, синну сол, шаҳр — ҳама дар як корт.

Дар барномасозӣ ҳам ҳамин тавр. Объект — ин тағйирёбандаест, ки дар дохилаш якчанд қимат дорад, ва ҳар қимат ном дорад.

let person = { name: "Алӣ", age: 25, city: "Душанбе" } — ин корти шахс ҳаст.

Ёдатон ҳаст рӯйхат? Он қиматҳоро бо шумора нигоҳ медошт. Объект — бо ном.

person.name — Алӣ. person.age — бисту панҷ.

Иваз кардан ҳам осон: person.age = 26 — ҳамон қуттии age.

Объект дар ҳама ҷо ҳаст: профили Instagramатон, ки маълумотҳоятонро дорад, мошин, мағоза.

Объект = шиноснома барои барнома ҳаст, ки дар он маълумотҳо нигоҳ дошта мешаванд: ном ва қимат.

## Код дар видео (санҷидашуда дар Node.js)
```js
let person = { name: "Алӣ", age: 25, city: "Душанбе" };
console.log(person.name);   // Алӣ
console.log(person.age);    // 25
person.age = 26;
console.log(person.age);    // 26
```

## Санҷиш (дар экран)
```js

person.age = 30;
console.log(person.name, person.age);   // ?
```
Ҷавоби дуруст: **Алӣ 30**. Ҷавобро дар ролик нагӯем.

## Нақшаи тасвир
| Қисм | Тасвир |
|---|---|
| Хук | 10 тағйирёбанда (`name1`, `age1`, `city1`…) ба як корти `{ }` ҷамъ мешаванд; «Чӣ тавр?» |
| Шиноснома | Корт: акс-нишона, «ном / синну сол / шаҳр» |
| Объект | Корт ба блоки `{ name, age, city }` табдил меёбад (IDE) |
| Рӯйхат vs объект | Рӯйхат: `[0] [1] [2]`; объект: `name` `age` `city` — бо тир аз дарси 4 |
| Нуқта | `person.name` → «Алӣ», `person.age` → 25 (терминал) |
| Иваз | Қуттии `age` (25 → 26) дар дохили корт, «поп» |
| Дар ҳаёт | Профили Instagram, мошин, мағоза — се корт |
| Хулоса | «ОБЪЕКТ = ном + қимат» |
| Санҷиш | Код + «?», соат |
| Охир | Шарҳ «ОБЪЕКТ» → баннери «Видеои пурра дар YouTube» → корти «Дарси 7: Хатогӣ» |
