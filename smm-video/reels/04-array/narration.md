# Reels 4 — «Рӯйхат (array)» (~70–75 сония) — нусхаи 2 (матни муаллиф + санҷиш бо рӯйхати харид)

Қоида (ҳамон, ки дар «Давр» кор кард): хук бо натиҷа, «Дарси 4 / 12», пайвастагӣ бо дарсҳои 1–3, калимаи рамз.

## Матн (барои субтитрҳо)

**Барои сад рақам сад тағйирёбанда лозим нест — як рӯйхат кифоя аст. Чӣ тавр?**

Рӯйхат!

Тасаввур кунед, ки рӯйхати харид доред: нон, шир, тухм, себ, нок. Панҷ чиз дар як ҷой.

Дар барномасозӣ рӯйхат — ин тағйирёбандаест, ки дар дохилаш якчанд қимат дорад. Номаш «array».

let fruits = ["себ", "нок", "ангур"] — ин ҳамон тағйирёбанда, яъне қуттӣ аз дарси як. Танҳо дар дохилаш се қимат аст.

Ҳар қимат шумора дорад. Диққат: шумора аз сифр оғоз мешавад! fruits[0] — себ, fruits[1] — нок, fruits[2] — ангур.

fruits.length нишон медиҳад, ки чанд қимат аст: се.

Қимати навро илова кунем? fruits.push("анор") — ба охири рӯйхат мегузорад.

Рӯйхат ва давр бо ҳам алоқаманд ҳастанд. for (let i = 0; i < fruits.length; i++) — давр аз дарси се. i аз сифр оғоз мешавад ва то охири рӯйхат меравад.

Ва console.log(fruits[i]) ҳар қимати рӯйхатро як-як нишон медиҳад: себ, нок, ангур, анор.

Дар ҳаёт ҳам рӯйхатҳо ҳама ҷо ҳастанд: рӯйхати мусиқӣ, суратҳо дар галерея, рӯйхати обуначиёни Instagram.

Рӯйхат = якчанд қимат + шумора аз сифр.

**Ва акнун санҷиш: ҳамон рӯйхати харид — нон, шир, тухм, себ, нок. «Тухм» бо кадом шумора истодааст? Ёдовар: шумора аз сифр оғоз мешавад. Ҷавобро дар шарҳ нависед.**

**Ҷавоб ва калимаи «РӮЙХАТ»-ро дар шарҳ нависед — шпаргалкаи бепулро ба Direct мефиристам!**

Дарси оянда — функсия: «рецепти» барнома. Обуна шавед, то аз ҷаҳони барномасозӣ бехабар намонед!

## Матн барои ElevenLabs v4 (калимаҳои англисӣ бо кириллӣ, рақамҳо бо калима)

Барои сад рақам сад тағйирёбанда лозим нест — як рӯйхат кифоя аст. Чӣ тавр?

Рӯйхат!

Тасаввур кунед, ки рӯйхати харид доред: нон, шир, тухм, себ, нок. Панҷ чиз дар як ҷой.

Дар барномасозӣ рӯйхат — ин тағйирёбандаест, ки дар дохилаш якчанд қимат дорад. Номаш эррей.

Лет фрутс баробари рӯйхати се мева: себ, нок, ангур — ин ҳамон тағйирёбанда, яъне қуттӣ аз дарси як. Танҳо дар дохилаш се қимат аст.

Ҳар қимат шумора дорад. Диққат: шумора аз сифр оғоз мешавад! Фрутс сифр — себ, фрутс як — нок, фрутс ду — ангур.

Фрутс лэнгс нишон медиҳад, ки чанд қимат аст: се.

Қимати навро илова кунем? Фрутс пуш анор — ба охири рӯйхат мегузорад.

Рӯйхат ва давр бо ҳам алоқаманд ҳастанд. Давр аз дарси се: ай, аз сифр оғоз мешавад ва то охири рӯйхат меравад.

Ва консол лог фрутс ай, ҳар қимати рӯйхатро як-як нишон медиҳад: себ, нок, ангур, анор.

Дар ҳаёт ҳам рӯйхатҳо ҳама ҷо ҳастанд: рӯйхати мусиқӣ, суратҳо дар галерея, рӯйхати обуначиёни Инстаграм.

Рӯйхат баробари якчанд қимат ва шумора аз сифр.

Ва акнун санҷиш: ҳамон рӯйхати харид — нон, шир, тухм, себ, нок. «Тухм» бо кадом шумора истодааст? Ёдовар: шумора аз сифр оғоз мешавад. Ҷавобро дар шарҳ нависед.

Ҷавоб ва калимаи «РӮЙХАТ»-ро дар шарҳ нависед — шпаргалкаи бепулро ба Директ мефиристам!

Дарси оянда — функсия: «рецепти» барнома. Обуна шавед, то аз ҷаҳони барномасозӣ бехабар намонед!

## Код дар видео
```js
let fruits = ["себ", "нок", "ангур"];
console.log(fruits[1]);        // нок
console.log(fruits.length);    // 3
fruits.push("анор");

for (let i = 0; i < fruits.length; i++) {
  console.log(fruits[i]);
}
```

## Санҷиш (дар экран, бе код)
Рӯйхати харид бо рақамҳо дар болои ҳар чиз ва якеи онҳо пинҳон:
```
0 нон   1 шир   ? тухм   3 себ   4 нок
```
Ҷавоби дуруст: **2** (на 3: шумора аз сифр оғоз мешавад). Ҷавобро дар ролик нагӯем.

## Нақшаи тасвир
| Қисм | Тасвир |
|---|---|
| Хук | Ҳисобкунаки «100 тағйирёбанда» ба як рӯйхат-қатор табдил меёбад; «Чӣ тавр?» |
| Рӯйхати харид | 🍞🥛🥚🍎🍐 дар як варақа, «5 чиз дар як ҷой» |
| Array | Як тағйирёбанда (қуттӣ) бо се ҷойи шумурдашуда: [0] [1] [2] — «себ», «нок», «ангур» |
| Шумора аз сифр | Рақамҳои 0, 1, 2 дар болои ҷойҳо бо урёнии зард, «ДИҚҚАТ: аз 0!» |
| length / push | «3» ва «анор» бо садои «поп» ба қатор илова мешавад |
| Рӯйхат + давр | i (тағйирёбанда аз дарси 3) аз қатор мегузарад ва ҳар як ҷойро равшан мекунад; терминал чоп мекунад |
| Дар ҳаёт | Плейлист, галерея, рӯйхати обуначиён |
| Хулоса | «РӮЙХАТ = якчанд қимат + шумора аз 0» |
| Санҷиш | Рӯйхати харид (нон, шир, тухм, себ, нок) бо рақамҳо 0–4, дар болои «тухм» «?», соат |
| Охир | Шарҳ «РӮЙХАТ» → баннери шпаргалка → корти «Дарси 5: Функсия» |
