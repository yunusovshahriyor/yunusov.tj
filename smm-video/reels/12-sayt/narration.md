# Reels 12 — «Сайт чӣ тавр кор мекунад?» (~85–95 сония) — нусхаи 2 (навшуда, интизори тасдиқ)

Мавзӯъ: **дарси 12 аз 13** — «Сайт чӣ тавр кор мекунад» (клиент → сервер → ҷавоб). Рилси 11 бо ҷумлаи «Дарси оянда — сайт чӣ тавр кор мекунад» тамом мешавад, ин ролик идомаи мустақими он аст.
Нусхаи нав аз нусхаи 1 чӣ фарқ дорад:
1. **Пайвастагӣ бо дарси 11:** ҳамон истилоҳҳо — HTML = **скелет**, CSS = **либос**, JavaScript = **рафтор** (чӣ кор мекунад). Дар ин ролик ин се чиз ҳамчун **се файл** аз сервер меоянд: `index.html`, `style.css`, `script.js`.
2. **Хук аз дарси 11:** «Шумо саҳифа сохтед — чӣ тавр он ба телефони дигарон мерасад?»
3. **Дарсӣ бештар:** браузер аввал `index.html`-ро мегирад, дар дохили он `style.css` ва `script.js` ишора шудаанд, браузер онҳоро низ мепурсад (воқеан ҳамин тавр аст).
4. **Амали худатон:** F12 → ҷадвали **Network** (дархостҳо ва ҷавобҳоро мебинед).
5. **Дарозӣ:** ~85–95 сония (қоидаи нав: то 120 с).
Қоида: хук бо натиҷа, «Дарси 12 / 13», даъват ба YouTube: пайванд дар Био-и профил (бе калимаи рамз ва бот).
Фикри ягона: **сайт = дархост + ҷавоб.** Мисоли ҳаётӣ: ресторан (меҳмон — браузер, ошхона — сервер, официант — интернет).
Услуб: VS Code Dark + бунафш, мисли дарсҳо; шапка нест.

## Дар экран (схема, бо воқеият мувофиқ)
```
Браузер → Сервер   (дархост, request)
GET yunusov.tj

Сервер → Браузер   (ҷавоб, response)
200 OK
index.html   — скелет (HTML)
style.css    — либос (CSS)
script.js    — рафтор (JavaScript)
```
`GET` — дархости гирифтани саҳифа; `200 OK` — ҷавоби муваффақ. Дар F12 → Network ҳамин ҷадвал бо номи файлҳо дида мешавад.

## Санҷиш (дар экран)
«Тугмаи «Лайк» пахш шуд. Браузер ба сервер **чӣ** мефиристад?» — ду корт: «дархост» / «ҷавоб». Ҷавоби дуруст: **дархост** (браузер мепурсад, сервер ҷавоб медиҳад). Ҷавобро дар ролик нагӯем.
