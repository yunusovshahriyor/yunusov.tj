# Reels 3 — «Давр: loop» (~65–70 сония)

## Матн (барои хондан ва субтитрҳо)

Давр?

Тасаввур кунед, ки бояд сад бор «Салом» нависед. Шумо хаста мешавед. Компютер — не.

Дар варзиш мураббӣ мегӯяд: даҳ бор нишаст-хез кунед. Шумо ҳисоб мекунед: як, ду, се… то даҳ. Ин давр аст.

Дар барномасозӣ давр — такрори як амал чанд маротиба. Номаш «for».

for (let i = 1; i <= 10; i++) — се қисм дорад. Аз куҷо оғоз мекунем: i баробари як. То кай: то даҳ. Ва қадам: ҳар бор як илова мекунем.

Ин i ҳамон қуттӣ аз дарси як аст! Қиматаш ҳар давр иваз мешавад: як, ду, се…

Ва i <= 10 ҳамон шарт аз дарси ду. То шарт дуруст аст, давр идома меёбад. Нодуруст шуд — бас.

Даҳро ба ҳазор иваз кунед — компютер ҳазор бор такрор мекунад, камтар аз як сония.

Шумо ҳар рӯз даврҳоро мебинед: лентаи Instagram постҳоро як-як нишон медиҳад, бозӣ экранро ҳар сония нав мекунад.

Давр = оғоз + шарт + қадам.

Ва акнун санҷиш: агар i аз сифр оғоз шавад ва шарт i < 3 бошад, барнома чанд бор «Салом» мегӯяд? Ҷавобро дар шарҳ нависед.

Дарси оянда — рӯйхат, «array»: чӣ тавр бисёр қуттиҳоро якҷоя нигоҳ дорем. Обуна шавед, то аз ҷаҳони барномасозӣ бехабар намонед!

## Код дар видео
```js
for (let i = 1; i <= 10; i++) {
  console.log("Нишаст-хез " + i);
}
```
Санҷиш (ҷавоб: 3 бор — i = 0, 1, 2):
```js
for (let i = 0; i < 3; i++) {
  console.log("Салом");
}
```

## Нақшаи тасвир
| Қисм | Тасвир |
|---|---|
| Хук | «ДАВР?» калон, тирчаи 🔁 чарх мезанад; ҳисобкунаки «Салом ×100» зуд пур мешавад |
| Хаста / не | Одами хаста 😮‍💨 ва компютер ⚡ |
| Варзиш | Ҳисобкунак 1 → 10 бо ҳар «як, ду, се» (садои тик) |
| for | Терминал: `for (...)` сатр ба сатр; се қисм бо се ранг ҷудо: оғоз / шарт / қадам |
| Пайвастагӣ | Қуттии `i` (мисли `age`) — рақам дар он 1 → 2 → 3 иваз мешавад; тамғаи «ДАРСИ 1» |
| Шарт | Диаграммаи `i <= 10 ?` — сабз: боз давр, сурх: бас (мисли дарси 2) |
| Ҳазор | Ҳисобкунак 10 → 1000 дар як лаҳза, «⚡ < 1 с» |
| Дар ҳаёт | Лентаи постҳо, ки ҳаракат мекунад; экрани бозӣ |
| Хулоса | «ДАВР = оғоз + шарт + қадам» |
| Санҷиш | Баннери «САНҶИШ», код бо `i = 0; i < 3`, «?» бо соат |
| Охир | Корти «Дарси 4: Рӯйхат (array)» ва тугмаи «Обуна шавед» |
