## Дар экран (код/схема, бо воқеият мувофиқ)
```
Браузер → Сервер   (дархост, request)
GET yunusov.tj

Сервер → Браузер   (ҷавоб, response)
200 OK
HTML + CSS + JS
```
`200 OK` — рамзи ҷавоби муваффақ дар HTTP; `GET` — дархости гирифтани саҳифа. Дигар код нест.

## Санҷиш (дар экран)
«Тугмаи «Лайк» пахш шуд. Браузер ба сервер **чӣ** мефиристад?» — корти «дархост» ва «ҷавоб». Ҷавоби дуруст: **дархост** (браузер мепурсад, сервер ҷавоб медиҳад). Ҷавобро дар ролик нагӯем.
