## Код дар видео (санҷидашуда дар браузер)
```html
<h1>Вазифаҳои ман</h1>
<p>нон харидан</p>
```
```css
h1 { color: red; }
p  { font-size: 20px; }
```
Натиҷа: сарлавҳа сурх, абзац бо ҳарфи 20px.
