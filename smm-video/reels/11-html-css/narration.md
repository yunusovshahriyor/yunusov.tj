## Матн (барои субтитрҳо)

**Лоиҳаи To-Do-и мо ҳоло танҳо дар консол кор мекунад. Чӣ тавр онро зебо ва дар браузер нишон диҳем?**

Намуди барнома!

Тасаввур кунед, ки хона месозед. Аввал девор ва ҳуҷраҳо лозиманд — скелет. Баъд ранг, парда ва мебел — намуд.

Дар сайт ҳам ҳамин тавр. Ду забон ҳаст: HTML ва CSS.

HTML — скелет. Он мегӯяд, ки дар саҳифа чӣ ҳаст: сарлавҳа, тугма, матн.

Мисол: h1 — сарлавҳаи калон. Button — тугма. Ҳар чиз дар байни ду барчасп аст: кушода ва пӯшида.

Ҳоло саҳифа ҳаст, аммо оддӣ ва хира. Ин ҷо CSS ёрӣ медиҳад.

CSS — либос. Он мегӯяд, ки чӣ гуна менамояд: ранг, андоза, гӯшаҳои мудаввар.

Навиштан осон аст: номи чиз, баъд қавси системавӣ ва дар дохили он — қоида. Масалан, button: background — сабз, border-radius — дувоздаҳ.

Ва тугма дарҳол сабзу мудаввар шуд!

Хулоса: HTML — чӣ ҳаст. CSS — чӣ гуна менамояд. Ва JavaScript — чӣ кор мекунад.

**Ва акнун санҷиш: h1 { color: red }. Ранги кадом чиз сурх мешавад? Ҷавобро дар шарҳ нависед.**

Дарси оянда — сайт чӣ тавр кор мекунад. Обуна шавед, то аз ҷаҳони барномасозӣ бехабар намонед!

## Код дар видео
```html
<h1>Вазифаҳо</h1>
<button>Илова</button>
```
```css
button {
  background: green;
  border-radius: 12px;
}
```
(Дар кадр: пеш аз CSS — тугмаи хокистарии оддӣ; баъд — сабз ва мудаввар. Код санҷиши иҷро надорад — тавассути браузер дар кадр нишон дода мешавад.)

## Санҷиш (дар экран)

Ҷавоби дуруст: **сарлавҳаи h1** (тугма тағйир намешавад). Ҷавобро дар ролик нагӯем.
