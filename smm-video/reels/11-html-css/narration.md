## Матн (барои субтитрҳо)

**To-Do-и мо кор мекунад — вале дар экран танҳо матни сиёҳ. Чӣ тавр онро саҳифаи зебо кунем?**

Намуди барнома!

Тасаввур кунед, ки хона месозед. Аввал — девор, дар ва тиреза. Баъд — ранг, парда ва мебел. Саҳифаи сайт ҳам ҳамин тавр сохта мешавад: аввал сохтор, баъд намуд.

Қисми якум — HTML. Ин девору дарҳост: чӣ ҳаст дар саҳифа. HTML бо теғ кор мекунад. Теғ — калима дар кунҷҳо: h1, ul, li. Ҳар теғ кушода мешавад ва баста мешавад.

Теғи h1 — сарлавҳа. «Вазифаҳои ман» дар дохили он. Ёдатон ҳаст рӯйхат аз дарси чаҳорум? Дар HTML рӯйхат — теғи ul, ва ҳар вазифа — теғи li: «нон харидан», «дарс хондан».

Саҳифа тайёр — вале сиёҳ ва оддӣ. Акнун CSS.

Қисми дуюм — CSS. Ин ранг ва ороиш: чӣ гуна менамояд. Қоидаи CSS аз се қисм иборат аст: ба кӣ — h1; кадом хосият — color; чӣ қимат — red. Дар охир — нуқта-вергул.

h1, акколада, color: red — ва сарлавҳа сурх шуд! Боз як қоида: li, font-size: 20px — вазифаҳо калонтар шуданд.

Хатои маъмул: нуқта-вергулро фаромӯш кардан. Агар дар як қоида ду хосият бе нуқта-вергул нависед, браузер ҳарду хосиятро намефаҳмад — ва ранг иваз намешавад!

HTML — чӣ ҳаст. CSS — чӣ гуна менамояд.

## Код дар видео (санҷидашуда дар браузер)
```html
<h1>Вазифаҳои ман</h1>
<ul>
  <li>нон харидан</li>
  <li>дарс хондан</li>
</ul>
```
```css
h1 { color: red; }
li { font-size: 20px; }
```
Хатои маъмул (дар видео бо ✖):
```css
h1 { color: red font-size: 40px; }   /* ✖ бе нуқта-вергул: ҳарду хосият кор намекунанд */
h1 { color: red; font-size: 40px; }  /* ✔ */
```
