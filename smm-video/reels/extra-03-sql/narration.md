# Reels (иловагӣ, мотиватсионӣ) — «Пойгоҳи маълумот чист? Барои ҳама» (~105–115 сония) — нусхаи 3 (интизори тасдиқ)

Нусхаи 3 барои **ҳама касон**, на танҳо барномасозон: муаллим, табиб, соҳибкор, деҳқон, донишҷӯ. Калимаҳои техникӣ кам; ҳар истилоҳ бо мисоли ҳаётӣ шарҳ дода мешавад; ҷумлаҳо кӯтоҳ ва оддӣ.
Манбаъ: видеои «Что такое SQL-база данных» (@glyzin.ai) — ман сенария ва тасвирҳои онро такрор намекунам; мавзӯъ умумист, матн, мисолҳо (дафтари мағоза, харидорон, харидҳо) ва тарҳ — аз худамон.
Дарозӣ: тибқи қоидаи нав (45–120 с) ~105–115 с. «Транзаксия», «СУБД», муносибатҳои мураккаб — рилсҳои алоҳида.
Фикри ягона: **пойгоҳи маълумот — ин дафтари хубсохташуда; ҳар кас метавонад онро фаҳмад ва ёд гирад.**
Оҳанг: мотиватсионӣ, самимӣ, бе тарсонидан; бе ваъдаҳои «дар як ҳафта» ва бе рақамҳои дурӯғ.
Код санҷида шуд дар SQLite (Node.js) — натиҷа дар поён.

## Матн (барои субтитрҳо)

**Телефони шумо садҳо ном ва рақамро нигоҳ медорад, ва шумо ҳар касро дар як сония меёбед. Чӣ тавр?**

Базаи маълумот!

Калима тарсонанда ба назар мерасад, аммо мазмуни он оддӣ аст: ин дафтари хубсохташуда аст.

Тасаввур кунед, ки дафтарчаи мағозаи шумо ҳаст. Ҳар як сатр — як харидор: ном ва шаҳр. Ин ҷадвал аст. Сатр — як нафар, сутун — як хосият.

Ҳоло дар дафтар панҷ харидор ҳаст — ҳама чиз равшан. Аммо агар панҷ ҳазор бошад? Бо дасти худ ҷустуҷӯ кардан имконнопазир аст.

Барои ин забони махсус ҳаст: SQL. Он мисли ҷумлаи оддӣ аст: гир ном аз харидорон, ки шаҳр — Душанбе.

SELECT name FROM customers WHERE city = 'Душанбе'. Ҷавоб омад: Алӣ ва Фарҳод — дар як сония, ҳатто агар панҷ ҳазор нафар бошанд.

Мушкили дигар: ду харидор Алӣ ном доранд. Чӣ тавр онҳоро фарқ кунем? Ба ҳар сатр рақами якто медиҳем — мисли рақами шиноснома. Ин калиди асосӣ аст.

Ҷадвали дуюм — харидҳо. Дар он ном навишта намешавад, танҳо рақами харидор — мисли чек. Агар ном иваз шавад, онро танҳо дар як ҷой ислоҳ мекунем. Ҷадвалҳо бо рақам ба ҳам пайваст мешаванд.

Ин дар ҳама соҳа кор мекунад: муаллим — журнали синф, табиб — рӯйхати беморон, деҳқон — ҳисоби ҳосил. Ҳамаи инҳо ҷадвал ҳастанд.

Ва муҳим: барои фаҳмидани асосҳо барномасоз будан лозим нест. Танҳо ҳар рӯз каме машқ кунед.

Базаи маълумот = ҷадвалҳо + рақамҳои пайвасткунанда. SQL — забон барои пурсидан.

**Ва акнун санҷиш: дар ҷадвал се харидор: Алӣ — Душанбе, Мариям — Хуҷанд, Фарҳод — Душанбе. Агар бипурсем «шаҳр — Хуҷанд», кӣ мебарояд? Ҷавобро дар шарҳ нависед.**

## Код дар видео (санҷидашуда дар SQLite)
```sql
CREATE TABLE customers (id INTEGER PRIMARY KEY, name TEXT, city TEXT);
CREATE TABLE purchases (customer_id INTEGER, item TEXT);

INSERT INTO customers (name, city) VALUES
  ('Алӣ', 'Душанбе'), ('Мариям', 'Хуҷанд'), ('Фарҳод', 'Душанбе'), ('Алӣ', 'Кӯлоб');
INSERT INTO purchases VALUES (1, 'нон'), (3, 'шир'), (4, 'себ');

SELECT name FROM customers WHERE city = 'Душанбе';
-- Алӣ
-- Фарҳод
```
Дар кадр: 1 Алӣ · 2 Мариям · 3 Фарҳод · 4 Алӣ (ду «Алӣ» бо id-и гуногун).

## Санҷиш (дар экран)
Ҷадвал: Алӣ — Душанбе · Мариям — Хуҷанд · Фарҳод — Душанбе.
```sql
SELECT name FROM customers WHERE city = 'Хуҷанд';   -- ?
```
Ҷавоби дуруст: **Мариям**. Ҷавобро дар ролик нагӯем.

## Нақшаи тасвир (тарҳи «шишагӣ», мисли рилси «Дар чанд вақт…»)
| Қисм | Тасвир |
|---|---|
| Хук | Телефон бо рӯйхати тамосҳо: ном, рақам; ҷустуҷӯ «Алӣ» → дарҳол ёфт мешавад; «Чӣ тавр?» |
| «Пойгоҳи маълумот!» | Калимаи калон + 🗄 |
| Тарсонанда → оддӣ | Калимаи «пойгоҳи маълумот» бо нишонаи ⚠ ба 📒 «дафтари хубсохташуда» мубаддал мешавад |
| Дафтарча → ҷадвал | Дафтарчаи мағоза бо сатрҳо, сипас ҷадвал `ном · шаҳр`; «сатр = як нафар», «сутун = як хосият» |
| 5 → 5 000 | Ҷадвал аз 5 то 5 000 сатр меафзояд; даст дар болои он «имконнопазир» |
| SQL | Корти «SQL» + «забон, ки мисли ҷумла аст» |
| Запрос | Терминал: `SELECT name FROM customers WHERE city = 'Душанбе'` — калимаҳои калидӣ рангин ва тарҷумаи англисӣ |
| Натиҷа | Алӣ ва Фарҳод равшан, дигарон хира; «1 сония ⏱» |
| Ду «Алӣ» | Ду сатри Алӣ + рақамҳои 1 ва 4 (🔑 «калиди асосӣ — мисли рақами шиноснома») |
| Ҷадвали дуюм | `харидҳо` бо рақами харидор; хатти пайванд; «ном иваз шуд → як ҷо» |
| Соҳаҳо | Се корт: 📚 муаллим (журнал), 🩺 табиб (беморон), 🌾 деҳқон (ҳосил) |
| Мотиватсия | «барномасоз будан лозим нест» + тақвими 20 дақиқа (ёдгорӣ аз рилси «Дар чанд вақт…») |
| Хулоса | «ҶАДВАЛҲО + РАҚАМҲОИ ПАЙВАСТКУНАНДА» ва «SQL = забон барои пурсидан» |
| Санҷиш | Ҷадвал бо 3 харидор; `... WHERE city = 'Хуҷанд'` = `?` |
| Охир | Ролик бо санҷиш тамом мешавад (бе корти YouTube ва бе «дарси оянда» — тибқи матни муаллиф) |
