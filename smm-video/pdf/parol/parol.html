7 қоидаи пароли бехатар

Барои Instagram, Telegram, почта ва бонк — ҳамин 7 қоида кифоя аст.

1

Дароз: камаш 12 аломат

Ибораи дароз аз «Pa$$w0rd» қавӣтар аст. Масалан, 4 калимаи тасодуфӣ: себ-абр-чойник-ситора.

2

Барои ҳар сайт — пароли алоҳида

Агар як сайт рахна шавад, хакер ҳамон паролро дар дигар сайтҳо месанҷад. Пароли алоҳида — дигар ҳисобҳо бехатар.

3

Паролҳои маъмул ва маълумоти шахсӣ — не

123456, qwerty, password, санаи таваллуд, ном, рақами телефон — хакер инҳоро аввал месанҷад.

4

Менеҷери паролҳо

Паролҳоро дар хотир нигоҳ надоред — бигзор барнома нигоҳ дорад: Bitwarden, 1Password ё менеҷери дарунсохти Google / Apple. Шумо танҳо як пароли асосиро ёд мегиред.

5

Тасдиқи дуқадама (2FA)

Дар Instagram, Telegram ва Gmail фаъол кунед. Ҳатто агар паролро донанд, бе коди дуюм ворид шуда наметавонанд. Барномаи тасдиқ (масалан, Google Authenticator) аз SMS бехатартар аст.

6

Паролро ба ҳеҷ кас нагӯед

На дар шарҳ, на дар Direct, на ба «корманди бонк». Сайти боэътимод паролро намепурсад — ҳатто барномасози он паролро намедонад.

7

Санҷед: пароли шумо дуздида нашудааст?

Дар haveibeenpwned.com почтаатонро нависед. Агар дар рӯйхат бошад — паролро ҳамон ҷо иваз кунед.

Генератори пароли худро созед

12 сатри JavaScript — ҳар бор «▶ Иҷро» = пароли нави 16-аломата.

parol.js
// Генератори пароли қавӣ
const harfho = "abcdefghijkmnpqrstuvwxyz" +
               "ABCDEFGHJKLMNPQRSTUVWXYZ" +
               "23456789!@#$%&*?";
const darozi = 16;

const tasodufi = crypto.getRandomValues(new Uint32Array(darozi));
let parol = "";
for (const r of tasodufi) {
  parol += harfho[r % harfho.length];
}
console.log(parol);

Чӣ тавр кор мекунад?

harfho— рӯйхати аломатҳо (64 аломат). Ҳарфҳои ба ҳам монанд (l, I, O, 0) нестанд.
darozi— дарозии пароль. Ба 20 иваз кунед — пароль боз ҳам қавӣтар.
crypto.getRandomValues— рақамҳои воқеан тасодуфии браузер (на Math.random).
for … of— давр аз дарси 3: барои ҳар рақам як аломат мегирад.
