# Reels 2 — «Шарт: if / else» (~75 сония)

## Матн (барои субтитрҳо)

Шарт?

Компютер чӣ тавр қарор қабул мекунад? Ҳамон тавре ки шумо ҳар субҳ қарор қабул мекунед.

Аз хона мебароед. Агар борон борад — чатр мегиред. Вагарна — айнаки офтобӣ.

Ин шарт аст. Дар барномасозӣ онро «if / else» мегӯянд: «if» — агар, «else» — вагарна.

Дар дарси гузашта қуттии «age»-ро сохтем ва дар он 25-ро гузоштем. Акнун бо он қарор қабул мекунем.

if (age >= 18) — агар синну сол аз 18 зиёд ё баробар бошад, барнома мегӯяд: «Хуш омадед!» else — вагарна: «Ҳанӯз барвақт аст».

Компютер қиматро месанҷад. Дуруст бошад — як роҳ. Нодуруст бошад — роҳи дигар. Ҳамагӣ ҳамин.

Дар ҳаёт шартҳо дар ҳама ҷо ҳастанд: светофор сабз бошад — мегузарем, сурх бошад — меистем. Парол дуруст бошад — ворид мешавед, нодуруст бошад — хато.

Шарт = савол + ду роҳ. Агар ҳа — як кор. Вагарна — кори дигар.

Ва акнун санҷиш: агар age 15 бошад, барнома чӣ мегӯяд? Ҷавобро дар шарҳ нависед. Дарси оянда — давр, «loop». Обуна шавед, то аз ҷаҳони барномасозӣ бехабар намонед!

## Матн барои ElevenLabs (рақамҳо бо калима, калимаҳои англисӣ бо кириллӣ)

Шарт?

Компютер чӣ тавр қарор қабул мекунад? Ҳамон тавре ки шумо ҳар субҳ қарор қабул мекунед.

Аз хона мебароед. Агар борон борад — чатр мегиред. Вагарна — айнаки офтобӣ.

Ин шарт аст. Дар барномасозӣ онро иф-элс мегӯянд: иф — агар, элс — вагарна.

Дар дарси гузашта қуттии эйдж-ро сохтем ва дар он бисту панҷро гузоштем. Акнун бо он қарор қабул мекунем.

Иф эйдж калон ё баробари ҳаждаҳ — агар синну сол аз ҳаждаҳ зиёд ё баробар бошад, барнома мегӯяд: Хуш омадед! Элс — вагарна: Ҳанӯз барвақт аст.

Компютер қиматро месанҷад. Дуруст бошад — як роҳ. Нодуруст бошад — роҳи дигар. Ҳамагӣ ҳамин.

Дар ҳаёт шартҳо дар ҳама ҷо ҳастанд: светофор сабз бошад — мегузарем, сурх бошад — меистем. Парол дуруст бошад — ворид мешавед, нодуруст бошад — хато.

Шарт баробари савол ва ду роҳ. Агар ҳа — як кор. Вагарна — кори дигар.

Ва акнун санҷиш: агар эйдж понздаҳ бошад, барнома чӣ мегӯяд? Ҷавобро дар шарҳ нависед. Дарси оянда — давр, луп. Обуна шавед, то аз ҷаҳони барномасозӣ бехабар намонед!

## Код дар видео
```js
let age = 25;

if (age >= 18) {
  console.log("Хуш омадед!");
} else {
  console.log("Ҳанӯз барвақт аст");
}
```

## Нақшаи тасвир
| Қисм | Тасвир |
|---|---|
| Хук | Аломати савол, ду тир ба ду тараф (ҳа / не) |
| Субҳ | Тиреза: абр ва борон → чатр; офтоб → айнак (ду кортро бо салиб ва ✓) |
| if / else | Тамғаҳо: «if = агар», «else = вагарна» |
| Қуттии age | Қуттии дарси 1 бо 25 бармегардад (пайвастагӣ бо силсила) |
| Код | Терминал, сатр ба сатр; `age >= 18` ҷудо мешавад, тир ба «Хуш омадед!» |
| Ду роҳ | Дарахти қарор: ✓ сабз → «Хуш омадед!», ✗ сурх → «Ҳанӯз барвақт» |
| Дар ҳаёт | Светофор (сабз/сурх), майдони парол (✓ / ✗) |
| Хулоса | «Шарт = савол + ду роҳ» |
| Санҷиш | Қуттӣ бо 15, аломати савол, тирезаи шарҳҳо |
| Охир | Корти «Дарси 3: Давр (loop)» ва тугмаи «Обуна шавед» |
