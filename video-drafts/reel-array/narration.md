# Reels 4 — «Рӯйхат (array)» (~70–75 сония)

Қоида (ҳамон, ки дар «Давр» кор кард): хук бо натиҷа, «Дарси 4 / 12», пайвастагӣ бо дарсҳои 1–3, калимаи рамз.

## Матн (барои субтитрҳо)

**Барои сад рақам сад қуттӣ лозим нест — як рӯйхат кифоя аст. Чӣ тавр?**

Рӯйхат?

Тасаввур кунед, ки рӯйхати харид доред: нон, шир, тухм. Се чиз дар як ҷой.

Дар барномасозӣ рӯйхат — ин қуттие, ки дар дохилаш якчанд қимат дорад. Номаш «array».

let fruits = ["себ", "нок", "ангур"] — ин ҳамон қуттӣ, яъне тағйирёбанда аз дарси як. Танҳо дар дохилаш се қимат аст.

Ҳар қимат шумора дорад. Диққат: шумора аз сифр оғоз мешавад! fruits[0] — себ, fruits[1] — нок, fruits[2] — ангур.

fruits.length нишон медиҳад, ки чанд қимат аст: се.

Қиматро илова кунем? fruits.push("анор") — ба охири рӯйхат мегузорад.

Рӯйхат ва давр дӯстони наздик ҳастанд. for (let i = 0; i < fruits.length; i++) — давр аз дарси се. i аз сифр оғоз мешавад ва то охири рӯйхат меравад.

Ва console.log(fruits[i]) ҳар қимати рӯйхатро як-як нишон медиҳад: себ, нок, ангур, анор.

Дар ҳаёт ҳам рӯйхат ҳама ҷо ҳаст: рӯйхати мусиқӣ, суратҳо дар галерея, постҳо дар лентаи Instagram.

Рӯйхат = якчанд қимат + шумора аз сифр.

Ва акнун санҷиш: let a = [10, 20, 30]. console.log(a[2]) чӣ нишон медиҳад?

**Ҷавоб ва калимаи «РӮЙХАТ»-ро дар шарҳ нависед — шпаргалкаи бепулро ба Direct мефиристам!**

Дарси оянда — функсия: «рецепти» барнома. Обуна шавед, то аз ҷаҳони барномасозӣ бехабар намонед!

## Матн барои ElevenLabs v4 (калимаҳои англисӣ бо кириллӣ, рақамҳо бо калима)

Барои сад рақам сад қуттӣ лозим нест — як рӯйхат кифоя аст. Чӣ тавр?

Рӯйхат?

Тасаввур кунед, ки рӯйхати харид доред: нон, шир, тухм. Се чиз дар як ҷой.

Дар барномасозӣ рӯйхат — ин қуттие, ки дар дохилаш якчанд қимат дорад. Номаш эррей.

Лет фрутс баробари рӯйхати се мева: себ, нок, ангур — ин ҳамон қуттӣ, яъне тағйирёбанда аз дарси як. Танҳо дар дохилаш се қимат аст.

Ҳар қимат шумора дорад. Диққат: шумора аз сифр оғоз мешавад! Фрутс сифр — себ, фрутс як — нок, фрутс ду — ангур.

Фрутс лэнгс нишон медиҳад, ки чанд қимат аст: се.

Қиматро илова кунем? Фрутс пуш анор — ба охири рӯйхат мегузорад.

Рӯйхат ва давр дӯстони наздик ҳастанд. Давр аз дарси се: ай аз сифр оғоз мешавад ва то охири рӯйхат меравад.

Ва консол лог фрутс ай ҳар қимати рӯйхатро як-як нишон медиҳад: себ, нок, ангур, анор.

Дар ҳаёт ҳам рӯйхат ҳама ҷо ҳаст: рӯйхати мусиқӣ, суратҳо дар галерея, постҳо дар лентаи Инстаграм.

Рӯйхат баробари якчанд қимат ва шумора аз сифр.

Ва акнун санҷиш: лет а баробари рӯйхати даҳ, бист, сӣ. Консол лог а ду чӣ нишон медиҳад?

Ҷавоб ва калимаи «РӮЙХАТ»-ро дар шарҳ нависед — шпаргалкаи бепулро ба Директ мефиристам!

Дарси оянда — функсия: «рецепти» барнома. Обуна шавед, то аз ҷаҳони барномасозӣ бехабар намонед!

## Код дар видео
```js
let fruits = ["себ", "нок", "ангур"];
console.log(fruits[1]);        // нок
console.log(fruits.length);    // 3
fruits.push("анор");

for (let i = 0; i < fruits.length; i++) {
  console.log(fruits[i]);
}
```
Санҷиш (ҷавоб: **30**, на 20, чунки шумора аз сифр оғоз мешавад):
```js
let a = [10, 20, 30];
console.log(a[2]);
```

## Нақшаи тасвир
| Қисм | Тасвир |
|---|---|
| Хук | Ҳисобкунаки «100 қуттӣ» кӯчак мешавад ва як рӯйхат-қатор ҷойгузин мешавад; «Чӣ тавр?» |
| Рӯйхати харид | 🍞🥛🥚 дар як варақа |
| Array | Як қуттӣ бо се ҷойи шумурдашуда: [0] [1] [2] — «себ», «нок», «ангур» |
| Шумора аз сифр | Рақамҳои 0, 1, 2 дар болои ҷойҳо бо урёнии зард, «ДИҚҚАТ: аз 0!» |
| length / push | «3» ва «анор» бо садои «поп» ба қатор илова мешавад |
| Рӯйхат + давр | i-и қуттӣ аз дарси 3 аз қатор мегузарад ва ҳар як ҷойро равшан мекунад; терминал чоп мекунад |
| Дар ҳаёт | Плейлист, галерея, лента |
| Хулоса | «РӮЙХАТ = якчанд қимат + шумора аз 0» |
| Санҷиш | `[10, 20, 30]`, «a[2] = ?», соат |
| Охир | Шарҳ «РӮЙХАТ» → баннери шпаргалка → корти «Дарси 5: Функсия» |
