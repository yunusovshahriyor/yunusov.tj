📋 Дарси 4: Рӯйхат (array) Барои сад рақам сад тағйирёбанда лозим нест — як рӯйхат кифоя аст. 
let fruits = ["себ", "нок", "ангур"];
console.log(fruits[1]);      // нок
console.log(fruits.length);  // 3
fruits.push("анор");

for (let i = 0; i < fruits.length; i++) {
  console.log(fruits[i]);
}
• Шумора аз 0 оғоз мешавад! fruits[0] — себ, fruits[1] — нок • .length — чанд қимат • .push() — ба охир илова мекунад • Рӯйхат ва давр бо ҳам алоқаманд ҳастанд (дарси 3) 🧠 Санҷиш: рӯйхати харид — нон, шир, тухм, себ, нок. «Тухм» бо кадом шумора истодааст? Ҷавобро дар шарҳ нависед 👇
