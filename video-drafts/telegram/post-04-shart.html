🔀 Дарси 2: Шарт (if / else) Компютер ҳамон тавр қарор мекунад, ки шумо субҳ: агар борон борад — чатр, вагарна — айнак ☂️😎 if — агар, else — вагарна. 
let age = 25;

if (age >= 18) {
  console.log("Хуш омадед!");
} else {
  console.log("Ҳанӯз барвақт");
}
Шарт = савол + ду роҳ: дуруст бошад — як роҳ, нодуруст — роҳи дигар. 🧠 Вазифа: шарти худро нависед: агар temperature > 30 бошад — «Гарм аст», вагарна — «Хунук аст». Дар шарҳ 👇 📲 Ролик дар Instagram: @shahriyor_yunusov
