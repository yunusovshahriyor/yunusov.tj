ДАРСИ 1

📦 Тағйирёбанда

Тағйирёбанда — қуттӣ бо ном, ки дар дохилаш қимат нигоҳ медорад. Қиматро иваз кардан мумкин аст.
let age = 25;   // қуттии нав
age = 26;       // қимати нав
console.log(age);
▶ Натиҷа
26

Се навъи асосии маълумот

let age = 26;              // рақам   (number)
const name = "Шаҳриёр";    // матн    (string)
let isStudent = true;      // ҳа / не (boolean)
let — қимат иваз мешавад
const — қимат доимист

Қоидаҳои ном

✓ age, userName, score2✗ 2score, user name, let

Номро бо ҳарф оғоз кунед, бе фосила. Калимаҳои дуюмро бо ҳарфи калон: userName.

ДАРСИ 2

🔀 Шарт: if / else

if — агар, else — вагарна. Шарт = савол + ду роҳ.
let age = 15;
if (age >= 18) {
  console.log("Хуш омадед!");
} else {
  console.log("Ҳанӯз барвақт");
}

Аломатҳои муқоиса

> калон< хурд=== баробар
>= калон ё баробар<= хурд ё баробар!== баробар нест

Зиёда аз ду роҳ: else if

let score = 75;
if (score >= 90) {
  console.log("Аъло");
} else if (score >= 70) {
  console.log("Хуб");
} else {
  console.log("Боз кӯшиш кунед");
}
▶ Натиҷа
Хуб
⚠️ Хатои маъмул: = қимат мегузорад, === муқоиса мекунад. Дар шарт ҳамеша ===.

ДАРСИ 3

🔁 Давр: for

Давр — такрори як амал чанд маротиба. Давр = оғоз + шарт + қадам.
let i = 1; i <= 10; i++
1 · оғоз2 · шарт3 · қадам
ҷамъи 1 то 100
let sum = 0;
for (let i = 1; i <= 100; i++) {
  sum = sum + i;
}
console.log(sum);
▶ Натиҷа
5050
ҷадвали зарб
for (let i = 1; i <= 3; i++) {
  console.log("7 × " + i + " = " + 7 * i);
}
▶ Натиҷа
7 × 1 = 7
7 × 2 = 14
7 × 3 = 21
⚠️ Давре, ки хотима намеёбад: агар қадамро (i++) фаромӯш кунед, шарт ҳамеша дуруст мемонад ва барнома «овезон» мешавад.

ЛОИҲАИ ХУРД

Ҳар се ғишт якҷоя

Барнома рақамҳои 1 то 6-ро месанҷад: ҷуфт ё тоқ?

juft-toq.js
for (let i = 1; i <= 6; i++) {       // 🔁 давр
  if (i % 2 === 0) {                   // 🔀 шарт
    console.log(i + " — ҷуфт");
  } else {
    console.log(i + " — тоқ");
  }
}
▶ Натиҷа
1 — тоқ
2 — ҷуфт
3 — тоқ
4 — ҷуфт
5 — тоқ
6 — ҷуфт
💡 i % 2 — бақияи тақсим ба 2. Агар бақия 0 бошад, рақам ҷуфт аст. Ва i — ҳамон 📦 тағйирёбанда.

🧠 Вазифаҳо (ҷавобҳо дар саҳифаи 7)

  1. Тағйирёбандаи myName созед ва «Салом, …!» нишон диҳед.
  2. Агар temperature > 30 — «Гарм аст», вагарна — «Хунук аст».
  3. Бо давр аз 10 то 1 баръакс ҳисоб кунед.

ҶАВОБҲО

Худро санҷед ✅

Санҷиши дарси 1: let age = 25; age = 26; → дар қуттӣ 26. Қимати нав кӯҳнаро иваз мекунад, ҷамъ намешавад.
Санҷиши дарси 2: age = 15 → «Ҳанӯз барвақт». 15 < 18, шарт нодуруст → else.
Санҷиши дарси 3: for (let i = 0; i < 3; i++) → 3 бор: i = 0, 1, 2.

Ҳалли вазифаҳо

// 1
let myName = "Нигина";
console.log("Салом, " + myName + "!");

// 2
let temperature = 34;
if (temperature > 30) {
  console.log("Гарм аст");
} else {
  console.log("Хунук аст");
}

// 3
for (let i = 10; i >= 1; i--) {
  console.log(i);
}

Салом, Нигина!
